[175. 组合两个表](https://leetcode.cn/problems/combine-two-tables/)
要搞清楚不同的连接方式有什么不同。
### 1.自然连接 
         `关系natural join关系`
自然连接只考虑在两个关系的模式中都出现的那些属性上取值相同的元组对（有共同属性且该属性的取值相同）。它不会重复列出在两个关系的模式中都出现的属性，只会出现一次。同时列出的顺序是先公共属性，然后是只出现在第一个关系的属性，再是只出现在第二个关系的属性。
```MySQL
select name,course_id
from student,takes
where student.ID=takes.ID;
```
这个代码用自然连接可以写作：
```MySQL
select name,course_id
from student natural join takes;
```
