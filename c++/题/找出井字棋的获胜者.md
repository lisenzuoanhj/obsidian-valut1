[1275. 找出井字棋的获胜者](https://leetcode.cn/problems/find-winner-on-a-tic-tac-toe-game/)
这个题。。因为一直想用Java写，想不明白又看题解，看了半天问了ai还是不会，最终放弃了用ai写的想法，学习了用c++的写法。
```cpp
class Solution {
public:
    string tictactoe(vector<vector<int>>& moves) {
        int tep[3][3];
        int i=1;
        for(auto&v:moves){
            tep[v[0]][v[1]]=i;
            i=-i;
        }
        for(int i=0;i<3;i++){
            if(abs(tep[i][0]+tep[i][1]+tep[i][2])==3 
            ||abs(tep[0][i]+tep[1][i]+tep[2][i])==3)
            {
               return tep[i][i]==1?"A":"B";
            }
        }

        if(abs(tep[0][0]+tep[1][1]+tep[2][2])==3
        ||abs(tep[0][2]+tep[1][1]+tep[2][0])==3)
        {
           return tep[1][1]==1?"A":"B";
        }
        return moves.size()==9?"Draw":"Pending";
    }
};
```

**其中的for循环相当于**
```
for (int i = 0; i < moves.size(); i++) {
    auto & v = moves[i];}
```
  对 `tep[v[0]][v[1]]=i;`这一串代码，v指代的是moves数组，假设moves数组里面有（1，2），那v\[0]指的就是1，v\[1]指的就是2。
