[#P1161开灯](https://www.luogu.com.cn/problem/P1161#ide)
看题解看到的很厉害的解法，用异或（同0异1）可以很好的表示灯的开关。
```cpp
#include<bits/stdc++.h>
double a;
int n, ans, x, t;
using namespace std;
int main()
{
	cin >> n;
	for (int i = 1; i <=n; i++) {
		cin >> a >> t;
		for (int i = 1; i <= t; i++) {
			x = (int)floor(a * i);
			ans ^= x;
		}
	}
	cout << ans;
	return 0;
}
```
