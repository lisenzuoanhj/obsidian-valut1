在 C++ 中，`floor` 是一个数学函数，用于**向下取整**。

## 基本功能

`floor` 函数返回**不大于**给定参数的最大整数值（double 类型）。

```cpp
#include <iostream>
#include <cmath>

int main() {
    std::cout << floor(3.7) << std::endl;   // 输出: 3
    std::cout << floor(3.2) << std::endl;   // 输出: 3
    std::cout << floor(3.0) << std::endl;   // 输出: 3
    std::cout << floor(-3.7) << std::endl;  // 输出: -4
    std::cout << floor(-3.2) << std::endl;  // 输出: -4
    
    return 0;
}
```

## 头文件

需要包含 `<cmath>` 头文件：
```cpp
#include <cmath>
```

## 相关函数

- **`ceil`** - 向上取整
  ```cpp
  ceil(3.2)  // 返回 4
  ceil(-3.2) // 返回 -3
  ```

- **`round`** - 四舍五入
  ```cpp
  round(3.2)  // 返回 3
  round(3.7)  // 返回 4
  round(-3.2) // 返回 -3
  ```

- **`trunc`** - 向零取整
  ```cpp
  trunc(3.7)  // 返回 3
  trunc(-3.7) // 返回 -3
  ```

## 实际应用示例

```cpp
#include <iostream>
#include <cmath>

int main() {
    double price = 19.99;
    double discount = 0.15;
    double finalPrice = price * (1 - discount);
    
    std::cout << "原价: " << price << std::endl;
    std::cout << "折扣后: " << finalPrice << std::endl;
    std::cout << "向下取整价格: " << floor(finalPrice) << std::endl;
    
    return 0;
}
```

输出：
```
原价: 19.99
折扣后: 16.9915
向下取整价格: 16
```
