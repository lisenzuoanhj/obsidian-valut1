### 通俗理解

注册输出参数是 JDBC 调用**带返回值的存储过程**时的**必要操作**—— 你可以把它想象成：

> 调用存储过程前，先给数据库 “打个招呼”：“我接下来要调用你的存储过程，它会返回一个第 3 个参数，类型是整数，你执行完后把这个值放到我指定的位置，我好读取”。

没有这一步，Java 程序无法识别存储过程的输出参数，也拿不到存储过程执行后的返回结果。

### 技术层面的核心解释

#### 1. 存储过程的参数类型

存储过程有三种参数类型（对应你之前的 `sp_borrow_book`）：

- `IN`：输入参数（Java → 数据库），比如 `p_reader_id`、`p_book_id`（你传给存储过程的值）；
- `OUT`：输出参数（数据库 → Java），比如 `p_result`（存储过程执行完返回给你的结果）；
- `INOUT`：输入输出参数（双向传递，极少用）。

#### 2. 为什么需要 “注册”？

JDBC 的 `CallableStatement` 是 “预编译” 的，在执行存储过程前，必须明确告诉它：

- 哪个位置的参数是输出参数（比如第 3 个 `?`）；
- 这个输出参数的数据库类型（比如 `INT`/`VARCHAR`）。

如果不注册，`CallableStatement` 只会处理输入参数，执行后无法读取输出参数的值（甚至会报错）。

### 结合你的代码实例拆解

#### 存储过程定义（回顾）

```sql
CREATE PROCEDURE sp_borrow_book(
    IN p_reader_id INT,   -- 输入参数1
    IN p_book_id INT,     -- 输入参数2
    OUT p_result INT      -- 输出参数3
)
```

#### Java 代码中的注册操作

```java
// 1. 准备调用存储过程的语句（3个?对应3个参数）
stmt = conn.prepareCall("{CALL sp_borrow_book(?, ?, ?)}");

// 2. 设置输入参数（IN类型，Java传给数据库）
stmt.setInt(1, readerId);  // 对应p_reader_id
stmt.setInt(2, bookId);    // 对应p_book_id

// 3. 注册输出参数（OUT类型，数据库返回给Java）
// 参数1：输出参数的位置（第3个?）
// 参数2：参数类型（Types.INTEGER对应MySQL的INT）
stmt.registerOutParameter(3, Types.INTEGER);

// 4. 执行存储过程
stmt.execute();

// 5. 读取输出参数的值（注册后才能读）
return stmt.getInt(3);
```

### 关键细节（新手必看）

#### 1. 注册的顺序和位置

- 输出参数的 “位置” 必须和存储过程的参数顺序一致（比如你的 `p_result` 是第 3 个参数，就注册第 3 个 `?`）；
- 先设置**输入参数**，再注册**输出参数**（顺序不强制，但建议统一，避免混乱）。

#### 2. 类型匹配（核心）

`registerOutParameter` 的第二个参数必须和存储过程的输出参数类型匹配，否则会报类型转换异常：

表格

|存储过程参数类型|Java 注册类型（Types）|
|---|---|
|INT|Types.INTEGER|
|VARCHAR|Types.VARCHAR|
|DATE|Types.DATE|
|DECIMAL|Types.DECIMAL|

比如你的 `p_result` 是 `INT`，就必须用 `Types.INTEGER`，不能用 `Types.VARCHAR`。

#### 3. 执行后才能读取

必须先调用 `stmt.execute()` 执行存储过程，再调用 `stmt.getInt(3)` 读取输出参数 —— 顺序反过来会报错（因为存储过程还没执行，没有返回值）。

### 对比：输入参数 vs 输出参数

表格

|操作|输入参数（IN）|输出参数（OUT）|
|---|---|---|
|目的|给存储过程传值|从存储过程取值|
|JDBC 方法|`setInt()`/`setString()` 等|`registerOutParameter()`|
|执行时机|执行存储过程**前**|执行存储过程**前**（注册）+ **后**（读取）|
|示例|`stmt.setInt(1, readerId)`|`stmt.registerOutParameter(3, Types.INTEGER)` + `stmt.getInt(3)`|

### 总结

1. 注册输出参数是 JDBC 调用带 `OUT` 类型参数的存储过程时的**必要步骤**，作用是告诉程序 “哪个参数是数据库返回的、类型是什么”；
2. 核心语法：`registerOutParameter(参数位置, 类型)`，必须和存储过程的输出参数位置、类型匹配；
3. 执行逻辑：设置输入参数 → 注册输出参数 → 执行存储过程 → 读取输出参数。

简单记：输入参数是 “你给数据库传值”，输出参数是 “数据库给你返回值”，注册就是 “提前告诉程序要接收这个返回值”。
