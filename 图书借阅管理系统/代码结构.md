```  
library-system/  
├── pom.xml                 # Maven配置  
├── sql/  
│   └── init.sql           # 数据库初始化脚本  
└── src/main/  
    ├── java/com/library/  # 后端代码  
    │   ├── dao/           # 数据访问层（操作数据库）  
    │   ├── entity/        # 实体类（映射数据库表）  
    │   ├── filter/        # 过滤器（权限/编码）
    │   ├── servlet/       # Servlet控制器  
    │   └── util/          # 工具类（数据库连接/日期）
    └── webapp/            # 前端&配置
	    ├── css/           # 样式文件  
        └── WEB-INF/            
	        ├── views/     # JSP视图  
            └── web.xml    # Web配置  
```

**pom.xml**：maven核心配置，可以管理依赖（如Servlet、JDBC、MyBatis、数据库驱动等），配置打包方式（war包，Web项目），指定jdk版本。

**init.sql**：数据库初始化：创建library_db库和8个核心表，定义了视图和存储过程（借阅/归还逻辑），插入初始测试数据。

**entity**：有Book,BorrowRecord,Category,Reader,User五个Java文件，分别对应图书类，借阅记录类，分类类，读者类，管理员类，每个类对应数据库的一个表，提供了get/set方法。

**dao**：定义了操作数据库的接口，实现了类/XML映射文件执行SQL（查询/新增/修改图书/借阅记录），可以直接调用init.sql创建的表/存储过程。

**servlet**：可以接收前端请求（如借阅图书、归还图书、查询图书），调用DAO层处理业务，并返回结果到JSP视图。

**filter**：作为过滤器，可以拦截所有Web请求（如登录验证：未登录不能借阅），有着编码过滤（统一UTF-8）和权限控制（admin/reader的区别）的作用。

**util**：它是数据库连接工具（JDBCUtil：获取数据库连接，连接library_db），是日期/字符串工具（处理借阅日期/逾期计算），以及验证码/加密工具（用户密码加密）。

**views**：控制前端页面（图书列表页、借阅页、读者管理页、逾期统计页），可以接收Servlet返回的数据并渲染。

**web.xml**：Web核心配置，负责注册Servlet/Filter（指定访问路径），配置欢迎页、错误页，初始化参数（如数据库连接参数）。
