```java
Connection conn = null;//声明数据库连接对象  
PreparedStatement stmt = null;//声明预编译的SQL语句对象  
ResultSet rs = null;//声明结果集对象，用于存放查询结果  
try {  
    conn = DBUtil.getConnection();//通过DButil获取数据库连接对象  
	stmt = conn.prepareStatement(sql);//使用连接对象和 SQL 创建 PreparedStatement 
	stmt.setInt(1, id);//把方法参数 id 设置到 SQL 的第 1 个?中  
    rs = stmt.executeQuery();
```
以上是所有Dao类里面最通用的声明。`executeQuery();`是每个类都会重载的函数。
