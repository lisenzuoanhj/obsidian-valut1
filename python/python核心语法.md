# 一、数据存储与运算

## 一、字面量和变量

#### 字面量：直接书写的固定值。

| 类型           | 说明                    | 举例                   |
| ------------ | --------------------- | -------------------- |
| 数字类型         | 整数（int）/浮点数/小数（float） | 10 -5 0 8.5 1.0 -3.5 |
| 布尔（bool）     | 表达现实生活中的逻辑，真或假        | True False           |
| 字符串（str）     | 描述文本的一种数据类型（双引号）      | "人生得意须尽欢"            |
| 空值（NoneType） | 表示空或无值，仅包含一个值None     | None                 |
| 数据容器         | 存储多项数据的容器             | 列表/元组/集合/字典          |

> [!NOTE] 说明
> 布尔类型本质就是数字类型，在涉及到数学运算时，会自动将**True转为1，False转为0**。


##### 变量：程序中用于存储单个数据的**容器**，通常会把经常发送变化的数据存储在变量中。

定义格式：`变量名 = 变量的值`
> [!NOTE] 说明
> python是动态类型语言，在程序运行的时候才进行类型检查，变量的类型可以在程序运行过程中改变（一个变量可以接收不同类型的值）。但在项目开发中，推荐变量只存储一种类型的数据。

python可以一次性定义多个变量，不同变量和值之间用逗号分隔。
```python
base,incr = 20.7,"增加"
```

##### 标识符是程序员在代码中为变量、函数、类等元素起的名字。

*命名规则*：
1.只能包含字母、数字、下划线
2.不能以数字开头
3.不能使用关键字：True、False、None、and、or、if、else、elif、for、while等
4.严格区分大小写，比如：age、Age、AGE是三个变量

*命名规范*：
1.见名知意
2.多个部分使用下划线连接（蛇形命名法）
3.英文字母全小写


## 二、常见数据类型

| 标准名称     | 描述  | 说明                        |
| -------- | --- | ------------------------- |
| int      | 整数  | 数字类型，存放整数，如：10，32         |

2.通过`isinstance()`检查数据是否属于指定的类型，返回的是一个bool值，具体语法为`isinstance(数据,类型)`

##### 字符串拼接
要将多个字符串拼接起来，可以直接使用`+`进行拼接。
```python
slogan = "人生得意须尽欢"+"莫使金樽空对月"
print(slogan)

s1 ="千金散尽还复来"
s2 ="烹羊宰牛且为乐"
print("李白：" + s1 + "，" + s2)
```

> [!NOTE] 说明
> `+`不能拼接字符串和非字符串，只能是字符串和字符串。（非字符串类型需转成字符串类型）

```python
s = 18
print("我今年" + s + "岁了") ❌

print("我今年" + str(s)+ "岁了")
# str(int数字)  将int类型的数字转为字符串
```

#### 字符串拼接存在的问题
1. 拼接繁琐
2. 破坏字符串的完整性
3. 需要进行类型转换

--> **字符串格式化**
1.通过`%占位符`的形式完成字符串和变量的快速拼接，且不需要类型转换
```python
age = 18
print("我今年%s岁了" % age) 

s1 ="千金散尽还复来"
s2 ="烹羊宰牛且为乐"
print("李白：%s，%s" % (s1,s2))
```

> [!NOTE] 说明
> 前面有多少个占位符（%s），后面就要有多少个变量（或数据），前后数量要一致。


2.通过`f"内容{变量/表达式}"`的形式来完成快速格式化，不用类型转换 。*（推荐）*
```python
age = 18
print(f"我今年 {age} 岁了" ) 

s1 ="千金散尽还复来"
s2 ="烹羊宰牛且为乐"
print(f"李白： {s1} , {s2} ")
```

## 三、输入与输出

#### 输入

input语句（函数）的功能就是获取键盘输入的数据，具体用法为`s = input(提示信息)`

print语句（函数）的功能就是将数据输出到控制台，具体语法为`print(数据)`



```python
name = input("请输入你的姓名：")
print(f"欢迎您，{name}")
```

> [!NOTE] 说明
> 所有键盘输入的数据都是字符串类型！


#### 数据类型转换

其他类型转为int类型：int(...)
其他类型转为str类型：str(...)
其他类型转为float类型：float(...)
其他类型转为bool类型：bool(...)

## 四、运算符

### 1.算术运算符

| 运算符 | 描述    | 举例说明                          |
| :-: | ----- | ----------------------------- |
|  +  | 加法    | 略                             |
|  -  | 减法    | 略                             |
|  *  | 乘法    | 略                             |
|  /  | 除法    | 10/5：10除以5，除法结果是**小数**        |
| //  | 整除    | 10//3：10整除3，整除结果为**整数**（向下取整） |
|  %  | 取余/求模 | 10%3：10模于3，结果是1（10除以3取余数）     |
| **  | 幂指数   | 10** 3 ：10的3次方                |

> [!NOTE] 算术运算符的优先级
> 从高到低： \*\* --> *   /  //  %  --> +  -  


0.5-0.5=0.1，为什么算成0.09999999998？
-->**精度缺失**：用于计算机底层是基于二进制进行数据的存储和处理，二进制无法准确的表示所有的小数，因此，涉及到浮点数的运算，可能会损失精度。


### 2.赋值运算符

| 运算符 | 描述       | 实例                                  |
| :-: | -------- | ----------------------------------- |
|  =  | 赋值运算符    | 把=右边的结果赋值给左边的变量，如num =1+2，结果num的值为3 |
| +=  | 加法赋值运算符  | num +=2等效于num = num + 2             |
| -=  | 减法赋值运算符  | num -=2等效于num = num - 2             |
| *=  | 乘法赋值运算符  | num *=2等效于num = num * 2             |
| /=  | 除法赋值运算符  | num /=2等效于num = num / 2             |
| %=  | 取模赋值运算符  | num %=2等效于num = num % 2             |
| //= | 取整除赋值运算符 | num //=2等效于num = num // 2           |
| **= | 幂赋值运算符   | num ** =2等效于num = num ** 2          |

### 4.逻辑运算符
逻辑运算符用于连接多个条件（布尔）表达式（其值为“真”或“假”），并返回一个最终布尔结果的运算符。

| 运算符 | 描述      | 实例                              |
| --- | ------- | ------------------------------- |
| and | 逻辑与（并且） | 同时成立才是符合条件的（左右都是True，结果才是True)  |
| or  | 逻辑或（或者） | 有一个符合要求的即可（左右有一个是True，结果就是True） |
| not | 逻辑非（取反） | 取反操作，True变成False，False变成True    |
