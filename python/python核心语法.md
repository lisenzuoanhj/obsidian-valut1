# 一、数据存储与运算

## 一、字面量和变量

#### 字面量：直接书写的固定值。

| 类型           | 说明                    | 举例                   |
| ------------ | --------------------- | -------------------- |
| 数字类型         | 整数（int）/浮点数/小数（float） | 10 -5 0 8.5 1.0 -3.5 |
| 布尔（bool）     | 表达现实生活中的逻辑，真或假        | True False           |
| 字符串（str）     | 描述文本的一种数据类型（双引号）      | "人生得意须尽欢"            |
| 空值（NoneType） | 表示空或无值，仅包含一个值None     | None                 |
| 数据容器         | 存储多项数据的容器             | 列表/元组/集合/字典          |

> [!NOTE] 说明
> 布尔类型本质就是数字类型，在涉及到数学运算时，会自动将**True转为1，False转为0**。


##### 变量：程序中用于存储单个数据的**容器**，通常会把经常发送变化的数据存储在变量中。

定义格式：`变量名 = 变量的值`
> [!NOTE] 说明
> python是动态类型语言，在程序运行的时候才进行类型检查，变量的类型可以在程序运行过程中改变（一个变量可以接收不同类型的值）。但在项目开发中，推荐变量只存储一种类型的数据。

python可以一次性定义多个变量，不同变量和值之间用逗号分隔。
```python
base,incr = 20.7,"增加"
```

##### 标识符是程序员在代码中为变量、函数、类等元素起的名字。

*命名规则*：
1.只能包含字母、数字、下划线
2.不能以数字开头
3.不能使用关键字：True、False、None、and、or、if、else、elif、for、while等
4.严格区分大小写，比如：age、Age、AGE是三个变量

*命名规范*：
1.见名知意
2.多个部分使用下划线连接（蛇形命名法）
3.英文字母全小写

##### 字符串拼接
要将多个字符串拼接起来，可以直接使用`+`进行拼接。
```python
slogan = "人生得意须尽欢"+"莫使金樽空对月"
print(slogan)

s1 ="千金散尽还复来"
s2 ="烹羊宰牛且为乐"
print("李白：" + s1 + "，" + s2)
```

> [!NOTE] 说明
> `+`不能拼接字符串和非字符串，只能是字符串和字符串。（非字符串类型需转成字符串类型）

```python
s = 18
print("我今年" + s + "岁了") ❌

print("我今年" + str(s)+ "岁了")
# str(int数字)  将int类型的数字转为字符串
```

#### 字符串拼接存在的问题
1. 拼接繁琐
2. 破坏字符串的完整性
3. 需要进行类型转换

--> **字符串格式化**
1.通过`%占位符`的形式完成字符串和变量的快速拼接，且不需要类型转换
```python
age = 18
print("我今年%s岁了" % age) 

s1 ="千金散尽还复来"
s2 ="烹羊宰牛且为乐"
print("李白：%s，%s" % (s1,s2))
```

> [!NOTE] 说明
> 前面有多少个占位符（%s），后面就要有多少个变量（或数据），前后数量要一致。


2.通过`f"内容{变量/表达式}"`的形式来完成快速格式化，不用类型转换 。*（推荐）*
```python
age = 18
print(f"我今年 {age} 岁了" ) 

s1 ="千金散尽还复来"
s2 ="烹羊宰牛且为乐"
print(f"李白： {s1} , {s2} ")
```

## 二、流程控制语句

### 1.条件判断
只有满足指定条件，才会执行对应的代码逻辑
if条件判断基本格式
```python
if 要判断的条件1:
	条件成立时，要执行的操作1
elif 要判断的条件2:  # elif可以写多个
	条件成立时，要执行的操作2
else:
	条件不成立时，要执行的操作3


year = int(input("请输入年份："))
if(year %100 != 0 and year %4 ==0) or (year %400 ==0):
	print(f"{year}是闰年")
else:
	print(f"{year}是平年")


a=int(input('请输入一个数字'))
if a>0:
     print('这是一个正数') 
elif a<0:
     print('这是一个负数')
else:
	 print("这是0")
```


> [!NOTE] 说明
> python中是通过缩进来描述代码归属的，归属于if代码块的语句，需要在前方缩进4个空格（Tab键）


### 2.结构模式匹配 match...case
结构模式匹配就是用一个清晰的模板去精准的匹配数据的结构和内容，匹配成功则执行相应的操作。
（图片）
**match...case语法**
```python
match 表达式:
    case 值1:
        操作1
    case 值2 if 条件表达式:
        操作2
    case 值3|值4:
        操作3
    case _:
        默认操作
```
应用场景：
- match：基于变量的多个固定值进行分支判断时，可以使用match模式匹配
- if：条件判断涉及复杂的逻辑判定、范围比较及组合条件时
### 3.循环
#### while循环
while循环的语法结构
```python
while 条件表达式:
    循环题语句1
    循环体语句2
    ...
else:  # 可不写
    条件为false，循环正常结束时执行

i= 0
while i<10:
    print("人生苦短")
    i +=1
else:
    print("循环结束，执行完毕")
```

> [!NOTE] 说明
> while循环通过条件表达式，来控制是否要进行下一次循环。


#### for循环
本质是一种**轮询遍历**机制，对一批内容进行逐个处理。

for循环结构
```python
for 元素 in 待处理数据集:
    循环体代码（对元素进行处理）
else:# 可不写
    循环结束时，执行的代码
 
 msg = "hello world"
 for i in msg:
     print(i)
else:
    print("循环结束")

```

for循环和while循环的应用场景
- while循环：用于在某个条件满足时一直循环，循环的次数通常是未知的，只知道循环开始和结束的条件。（关注循环条件）
- for循环：用于对一个已知的数据集进行遍历或已知次数的循环。（关注的是遍历每一个元素）

==**range语句**==
- 作用：生成指定规则的数字序列
- 用法1：`range(end)`->获取一个从0开始，到end结束的数字系列（不含end本身）
    - `range(5)`获取的数据是0，1，2，3，4
- 用法2：`range(start,end)`->获取一个从start开始，到end结束的数字序列（不含end本身）
     - `range(2，8)`获取的数据是2，3，4，5，6，7
- 用法3：`range(start,end,step)`->获取一个从start开始，到end结束的数字序列，step步长（不含end本身）
    - `range(0，10，2)`获取的数据是0，2，4，6，8

```python
# 用for循环计算1～100之间所有的奇数和
total = 0

for i in range(1,101)
    if i % 2 != 0
        total += i

print(f"1-100之间所有奇数的和为{total}")

# 可简化为
for i in range(1,101,2)
    total += i

# 计算100-500之间所有3的倍数的和
total = 0
for i in range(100,500)
    if(i % 3 == 0)
        total += i

print(f"100-200之间所有3的倍数的和为{total}")
```
