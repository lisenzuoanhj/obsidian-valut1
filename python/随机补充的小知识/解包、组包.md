解包(Unpacking)：将容器（元组、列表）解开成独立的元素，分别赋值给多个变量。
组包(Packing)：将多个值合并到一个容器（元组、列表）里。
```python
num_list1 = [19,23,54,64,875,20,109,232,123,54]  
num_list2 = [55,80,72,35,60,123,54,29,91]  
  

num = [*num_list1,*num_list2]
#for i in num_list2:  
#     num_list1.append(i)解包相当于合并

# 定义元组，组包
t1 = (5,7,9,1)
t2 = 5,7,9,1 

# 基础解包（变量数量要与容器的元素个数一致）
a,b,c,d = t1

# (*)扩展解包
x , *y , z = t2 # x为5,y为[7,9],z为1
s , * o = t2 # s为5,o为[7,9,1]
*o , e = t2 # o为[5,7,9],e为1
```


> [!NOTE] 说明
> 在元组解包时，* 表示收集剩余的所有元素，允许我们处理不确定数量的元素（生成列表，以便于可以进行进一步的处理。
