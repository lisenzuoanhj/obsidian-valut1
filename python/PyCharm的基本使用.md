#### 一、目录结构
在你打开或新建某个项目后，pc会自动生成`.venv`和`.idea`两个文件夹。
`.idea`：保存了项目的配置信息，基本上不用，pc会隐藏它。
`.venv`：是虚拟环境的目录，保存了项目的环境信息。它保证了每个项目都在一个相对独立的隔离的运行环境中运行，项目与项目直接互不影响。

#### 二、注释
在要注释的语句前加 `#` 。快捷键是`ctrl+/`。

#### 三、终止符和分隔符
换行表示终止，分隔语句用`;`。
```python
print("Hello World!")  
print("Hello Python!")
```
```python
print("Hello World!");print("Hello Python!")

# 两者的效果相同
```

#### 快速增加行
用 `shift + enter`。

#### 删除缩进
用 `shift+tab键`。

#### 列编辑
用`alt + shift`，鼠标按住起始行下移到终止行，即可同时编辑选中的所有行。

#### 快速删除行
`CTRL + Y`。在设置里面可以调整这个快捷键是删除行还是重做。
