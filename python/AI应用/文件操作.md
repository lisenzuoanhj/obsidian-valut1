日常外面操作文件时，基本分为三步操作：打开、读/写、关闭。

```python
# 1.打开文件
f = open("resources/望庐山瀑布.txt","r",encoding="utf-8")
k = open("resources/静夜思.txt","w",encoding="utf-8")

# 2.读取文件
content = f.read()
print(content)

# 3.写入文件
k.write("床前明月光，\n")
k.write("疑是地上霜。\n")
k.write("举头望明月，\n")
k.write("低头思故乡。\n")

# 4.关闭文件
f.colse()
k.close()
```


> [!NOTE] 编码：
> 是将字符（文字、数字、符号）转换为计算机能够存储和处理的数字代码的规则系统，如：ASCII、GBK、UTF-8。

注意：如果操作完文件并未调用close方法关闭文件，同时程序没有停止运行，那么这个文件将一直被python占用，无法操作。

#### 操作文件过程出现异常，无法关闭怎么办？

资源释放：
```python
c = open("resources/静夜思.txt","w",encoding="utf-8")  
try:  
	c.write("静夜思\n")  
	c.write("床前明月光，\n")  
	c.write("疑是地上霜。\n")  
	c.write("举头望明月，\n")  
	c.write("低头思故乡。\n")  
  
finally:
	c.close()

推荐！
with open("resources/静夜思.txt","w",encoding="utf-8") as c:
	c.write("静夜思\n")  
	c.write("床前明月光，\n")  
	c.write("疑是地上霜。\n")  
	c.write("举头望明月，\n")  
	c.write("低头思故乡。\n")  
```


> [!NOTE] 提示
> with语句（上下文管理）的核心作用就是确保资源总是被正确获取和释放（即使发生异常，也会被正确释放），也是项目开发中的推荐方式。


路径写法：
- 相对路径：相对于当前工作目录的路径。`resources/静夜思.txt`
	. ：当前目录（./是可以省略的）
	.. ：上一级目录

- 绝对路径：是从文件系统的根目录开始，完整的描述文件位置的路径。`G:\develop\PythonProject\py_project01\第三章\resources\静夜思.txt`
	反斜杠在字符串中表示的是转义字符，\n,\t，用双反斜杠`\\`，或者用一个正斜杠。


操作模式：
- r：只读的方式打开文件，指针放在文件的开头。（默认模式）
- w：只写入模式，从头编辑，原有内容会被删除；文件不存在则创建新文件。
- a：追加模式，新内容会被追加在原有内容之后；文件不存在则创建新文件。



### 读写json格式文件

JSON是软件开发中最常用的数据交换格式，而为了简化JSON数据是处理，在python标准库中就提供了处理JSON数据的核心模块json。

**序列化(json.dump(...))**
```python
import json

obj = {
	"name":"张三",
	"age":18,
	"gender":"男",
	"hobbies":["reading","swimming"]
}
with open("resources/seesion.json","w",encoding="utf-8") as f:
	json.dump(obj,f,ensure_ascii=False,indent=2)
	# ensure_ascii=False 用于处理不是ascii的字符，如中文
	# indent=2 缩进2格
```


**反序列化(json.load(...))**
```python
import json

with open("resources/seesion.json","r",encoding="utf-8") as f:
	obj = json.load(f)
	print(obj)
```
