
## 一、概述

**面向过程编程**
- 核心思想：把一个需求分解成一系列要执行的步骤，然后按照步骤依次执行这些任务（关注流程、步骤）。
- 适用场景：面向过程编程非常直接，适合简单、线性的任务。

**面向对象编程**
- 对象可以理解为现实中具体的人/物在程序中的数字化身（万物皆对象）。
- 它把一个人/物的特征和功能打包到一起，是面向对象编程的基本单元（关注是谁来帮我做这件事）。
- 特征 --> 属性
- 功能 --> 方法

**类与对象**
- 类：描述的是一组具有相同属性（特征）和方法（功能/行为）的模板。
- 对象：对象是类的实例，是基于类创建出来的（实例对象）。

> [!NOTE] 提示
> 对象是由类创建出来的，创建对象的过程，也称为对象的实例化，一个类可以创建无数个对象。


## 二、类与对象

### 1.类的定义
定义类的语法如下：
```python
不推荐！
# 定义类
class 类名:
	pass

# 创建对象 
对象名 = 类名()
对象名.属性名1 = 属性值1
对象名.属性名2 = 属性值2

class Car:
	pass

c1 = Car()
# 动态的为对象添加属性
c1.brand = "BNW"  
c1.name = "X5"  
c1.price = 500000  
print(c1.__dict__) # {'brand': 'BNW', 'name': 'X5', 'price': 500000}

推荐！！！
# 定义类
class 类名:
	def __init__(self,参数列表):
	self.属性名 = 参数值
	self.属性名 = 参数值

# 创建对象
对象名 = 类名(参数列表)

# 定义类  
class Car:  
    def __init__(self,c_brand,c_name,c_price):  
        self.brand = c_brand  
        self.name = c_name  
        self.price = c_price  
# 创建对象  
c1 =Car("BNW","X5",500000)  
print(c1.__dict__) # {'brand': 'BNW', 'name': 'X5', 'price': 500000}
```

1. [[__init__]]
2. self：方法的第一个参数，表示当前创建的实例对象

> [!NOTE] 说明
> 类名的命名遵循大驼峰命名法，每个单词的首字母都是大写，
> 单词之间没有分隔符，比如：UserInfo,UserAccount。
> `__dict__`是python中用户自定义类实例的一个特殊属性，用于以字典形式存储对象的属性。
> 定义在类的外面的称为函数，定义在类中的函数称为方法。


## 三、实例方法

在类中定义实例方法时，定义语法与之前学习的函数定义的方式是一致的。
```python
# 定义类
class 类名:
    def __init__(self,形参列表):
        self.属性名 = 参数值
        self.属性名 = 参数值
        
    def 方法名(self,形参列表):
        ...
        def 方法名(self,形参列表):
        ...
    
# 创建对象
对象名 = 类名(参数列表)
对象名.方法名(实参)

class Car:
    def __init__(self,brand,name,price):
        self.brand = brand
        self.name = name
        self.price = price
    
    def running(self):
        print(f"{self.brand}{self.name}正在高速行驶...")
    def total_cost(self,discount,rate):
        return self.price * discount +self.price * rate

c1 =Car("BNW","X5",500000)
total_price = c1.total_cost(0.9,0.1)
print(f"提车总价为：{total_price:.0f}")

c1.running()
```


## 四、魔法方法

魔法方法是指Python中提供的以双下划线开头和结尾的特殊方法，用于定义类的特殊行为，比如`__init__`。
魔法方法不需要人为手动调用的，Python会在合适的时机自动调用。

| 魔法方法                                 | 描述                                                                                                   |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `__init__`                           | 初始化方法                                                                                                |
| `__str__`                            | 字符串表示的方法                                                                                             |
| `__eq__`                             | 比较两个对象是否相等（equal）                                                                                    |
| `__lt__`,`__le__`,`__gt__`,` __ge__` | 支持比较两个对象的大小（小于（less than），小于等于（less than or equal），大于（greater than）,大于等于（greater than or equal））<br> |
