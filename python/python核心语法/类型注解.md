## 一、基本介绍

### 类型注解

类型注解是Python中的一种语法特性，用于明确标识变量、函数参数和返回值的数据类型，从而使代码更清晰、更安全、更易维护。

```python
# 定义变量（原）
a =695  
score = 93.3  
hobby = "python"  
flag = True  
pic =None  
  
name = ['A','B','C','D','E','F']  
phones ={"19271831793","18917837827"}  
options = {"count":0,"total":0}  
goods = ("手机",6999,1)

# 加入类型注解
a : int=695  
score: float= 93.34  
hobby: str= "python"  
flag : bool= True  
pic : None=None  
  
name : list[str | int]= ['A','B','C',103,459]  
phone: set[str]={"19271831793","18917837827"}  
options: dict[str,int]= {"count":0,"total":0}  
goods: tuple[str,int,int]= ("手机",6999,1)
```

### 类型推断
类型推断是指python解释器自动推断出变量、表达式或函数返回值的数据类型的能力，而无需开发者显式声明。


> [!NOTE] 说明
> 在对变量进行直接赋值，或者涉及到变量的运算、容器的推导等场景时，解释器会自动推导出变量的类型。
> 类型注解只是起到语法提示作用，并不会影响程序运行的结果。

使用类型注解的好处：
- 代码结构更清晰、代码逻辑更安全、易维护
- 更准确的代码自动提示
- 提前发现代码潜在问题

## 二、函数类型注解

为函数添加类型注解，其实主要就是为函数的参数和返回值添加类型注解，具体语法如下：
```python
def calc(scores:list[int]) -> float:
	return sum(scores) / len(scores)
def calc_data(scores: list[int]) -> tuple[int,int,float]:
	max_v = max(scores)
	min_v = min(scores)
	avg_v = sum(scores) / len(scores)
	return max_v,min_v,avg_v	
```

其中，`list[int]`是参数的类型， `-> float`是返回值的类型
