## 一、概述
数据容器是一种可以容纳多份数据的数据类型（容器），容纳的每一份数据称之为1个元素，每个元素都可以是任意类型的数据，如：字符串、数字、布尔等。
常见的5种数据容器：列表(list)、字符串(str)、元组(tuple)、集合(set)、字典(dict)

## 二、列表（list）
列表可以一次性存储多个数据（元素）。
定义：`列表名称 = [元素1,元素2,元素3,元素4,元素5...]`
特点：
- 可以存储不同类型的元素
- 元素有序、可以重复、元素可以修改
- 索引/下标从0开始，反向索引从-1开始（最后一个元素），反向索引都是负数

> [!NOTE] 说明
> 序列类型：容器中的元素按特点顺序排列的、可通过索引访问的容器类型称之为序列。

```python
# list  
n =[1,4,6,2,2,99,55,"A",True]  
print(type(n))  
  
#访问列表的元素  
#获取  
print(n[0])  
print(n[-9])  
  
# 修改 注意索引不能越界  
n[7] = "B"  
  
#删除  
del n[5]    
  
# 遍历  
for i in n:  
    print(i)
```

### 常见方法

| 方法        | 作用                                   | 样例               |
| --------- | ------------------------------------ | ---------------- |
| append()  | 在列表的**尾部**追加元素                       | s.append(100)    |
| insert()  | 在**指定索引之前**，插入该元素                    | s.insert(0,92)   |
| remove()  | 移除列表中**第一个匹配到**的值                    | s.remove(75)     |
| pop()     | 删除列表中**指定索引位置**的元素（如果未指定索引，默认删除最后一个） | s.pop(2)/s.pop() |
| sort()    | 对列表进行排序（列表元素的数据类型一致，才可以进行排序），默认从小到大  | s.sort()         |
| reverse() | 反转列表元素                               | s.reverse()      |


## 三、字符串（str）

字符串是字符的容器，一个字符串可以存放任意数量的字符，如："python" 'python '   """python"""
特点：不可变性（无法修改）、有序性、可迭代性。

### 1.基本操作
字符串中的每一个字符元素都有其对应的下标（索引），通过元素对应的索引，就可以获取到对应的元素。
[[切片]]
步长为正是从前往后截取，为负是从后往前街区。
```python
s = "hello python"
print(s[0:5:1])  #输出为 hello
print(s[-1:-7:-1]) #输出为nohtyp
```

### 2.常用方法

| 方法                      | 作用                             | 样例                     |
| ----------------------- | ------------------------------ | ---------------------- |
| find()                  | 在字符串中查找子串，返回第一次出现的索引位置，找不到返回-1 | s.find('Python')       |
| count()                 | 统计子串在字符串中出现的次数                 | s.count('H')           |
| upper()                 | 将字符串中所有字母转换为大写                 | s.upper()              |
| lower()                 | 将字符串中所有字母转换为小写                 | s.lower()              |
| split()                 | 将字符串按指定分隔符分割成列表                | s.split(' ')           |
| strip()                 | 去除字符串两端的空白字符或指定字符              | s.strip()/s.strip('*') |
| replace()               | 将字符串中的指定子串替换为新的子串              | s.replace('H','C')     |
| startswith()/endswith() | 检查字符串是否由指定子串开头/结束，返回布尔值        | s.startswith('P')      |

> [!NOTE] 说明
> 所有会产生变化的方法都是赋值给新的字符串，原字符串不会发生改变。

## 四、元组（tuple）

列表的特点是元素可重复，有序，且可以被修改；
元组则是**一旦定义完成，里面的元素就不可修改**了。适用于记录只能被查询的信息。
- 介绍：元组是不可变的序列，类似于列表，但创建后不可修改。 
- 特点：
    - 可以存储不同类型的元素
    - 元素可以重复、有序、**不可修改**（支持索引访问、切片）
- 定义：
```python
# 定义元组
元组名称 = (元素1,元素2, ...)
t1 = (5,7,9,1,56,5,3,8,2)
#  定义空元组
元组名称 = ()
元组名称 = tuple()
t2 = ()
t3 = tuple()

!!! 如果定义单元素的元组，单个元素后要加上“,”  
t3 = (100)  
print(type(t3)) # --><class 'int'>  
print(t3)  
  
t4 = (100,)  
print(type(t4)) # --><class 'tuple'>  
print(t4) #(100,)

```
- 方法：
    - count()：统计某个元素在元组中出现的次数
    - index()：查找某个元素在元组中的索引位置（第一次出现的位置）

### 元组的组包和解包
[[解包、组包]]

## 五、集合（set）
- 介绍：集合（set）是一种无序的、不可重复的、可修改的数据容器。
- 定义：
```python
# 定义集合
s1 = {"C","D","X","T","O","U"}

# 定义空集合
s2 = set()
```

> [!NOTE] 说明
> **空集合的定义不能用{}，{}表示的是空字典**；由于集合是无序的，因此是**不支持索引下标访问**的。
> 重复的元素会进行自动去重。

### 1.常见操作

| 操作                | 含义                                | 样例                  |
| ----------------- | --------------------------------- | ------------------- |
| add()             | 添加元素到集合中                          | s1.add('t')         |
| remove()          | 移除集合中的指定元素（指定元素不存在将报错）            | s1.remove('t')      |
| pop()             | 随机删除集合中的元素并返回                     | e=s1.pop()          |
| clear()           | 清空集合                              | s1.clear()          |
| difference()  `-` | 求取两个集合的差集（包含在第一个集合但是不包含在第二个集合的元素） | s1.difference(s2)   |
| union()      \|   | 求取两个集合的并集                         | s1.union(s2)        |
| intersection()  & | 求取两个集合的交集                         | s1.intersection(s2) |

## 六、字典（dict）
- 介绍：使用键值对（key:value）类型来存储数据，每一个键都对应一个值可以根据键(key)找到对应的值(value)。
- 特点：可修改、键值对（key:value）存储、键(key)不能重复。
- 定义：
```python
#定义字典
字典名称 = {key: value, key:value, key:value ...}
dict1 = {"王林": 675,"李慕婉": 608,"徐立国": 478, "王林": 700, ...}
#只保留一个700，675会被覆盖

#定义空字典
字典名称 = {}
字典名称 = dict()

#根据key获取value
值 = 字典名称[key]
score = dict1["李慕婉"]

#修改
dict1["李慕婉"] = 689

#遍历
for k in dict1:
	print(f"{k} : {dict1[k]}")
for item in dict1.items():
	print(f"{item[0]} : {item[1]}")
for k,v in dict1.items():
	print(f"{k} : {v}")
```


> [!NOTE] 说明
> 字典中的value可以是任何类型的数据，而key不能为可变的类型（如不能为列表list、集合set、字典dict）。
> key不能重复。如果重复，后面的值会覆盖前面的值。
> 字典没有索引下标，只能根据key获取value。


常用操作

| 类型  | 操作                 | 含义                          | 样例                      |
| --- | ------------------ | --------------------------- | ----------------------- |
| 添加  | 字典名称\[key] = value | 往指定字典中添加key-value键值对        | dict1\["涛哥"] = 688      |
| 删除  | 字典名称.pop(key)      | 删除字典中指定的key，并返回该key对应的value | score = dict1.pop("涛哥") |
| 删除  | del 字典名称\[key]     | 删除字典中指定的键值对                 | del dict1\["涛哥"]        |
| 修改  | 字典名称\[key] = value | 修改字典中指定的key对应的值             | dict1\["小智"] = 578      |
| 查询  | 字典名称\[key]         | 根据key获取value                | dict1\["涛哥"]            |
| 查询  | 字典名称.get(key)      | 根据key获取value                | dict1.get("涛哥")         |
| 查询  | 字典名称.keys()        | 获取所有的key                    | dict.keys()             |
| 查询  | 字典名称.values(       | 获取所有的value                  | dict1.values()          |
| 查询  | 字典名称.items()       | 获取所有的key-value键值对           | dict1.items()           |

```python
"""  
    案例:  
    开发一个教务管理系统，在该系统中可以维护和管理学员的成绩信息，具体需求如下：  
        1. 添加学生信息：根据提示录入学生姓名、语文、数学、英语成绩，录入完成保存到系统中。  
        2. 修改学生信息：要求输入要修改的学生姓名，然后再提示输入语文、数学、英语成绩，输入完成后修改学员信息。  
        3. 删除学生信息：要求输入要删除的学生姓名，根据姓名删除学生信息。  
        4. 查询学生信息：要求输入要查询的学生姓名，根据姓名查询学生信息并输出。  
        5. 列出所有学生：遍历所有学生信息并输出。  
        6. 统计班级成绩：统计班级语文、数学、英语成绩的最高分、最低分、平均分，以及语文、数学、英语最高分和最低分的学员姓名。  
        7. 退出系统。  
"""  
from unittest import case  
  
menu = """  
# # # # # # # # # # # # # # # # # # # # # # # # # # 【菜单】 # # # # # # # # # # # # # # # # # # # # # # # # # # # ##  1. 添加学生信息   2. 修改学生信息   3. 删除学生信息   4. 查询学生信息   5. 列出所有学生   6. 统计班级成绩   7. 退出系统       ## # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # # #  
"""  
print("欢迎使用教务管理系统 ~")  
# 字典套字典  
info = {}  
  
while True:  
    print(menu)  
    operate = input("请输入操作(1-7):")  
    match operate:  
        case '1': 
            name = input("请输入学生姓名：")  
            if name in info:  
                print("该学生已存在在系统中，如同名请在名字末尾加大写字母以区分~")  
                continue  
            chinese_score = float(input("请输入该学生的语文成绩："))  
            math_score = float(input("请输入该学生的数学成绩："))  
            english_score = float(input("请输入该学生的英语成绩："))  
            info[name] = {"chinese":chinese_score, "math":math_score, "english":english_score}  
            print("学生信息已保存~")  
  
        case '2': 
            change_name = input("请输入要修改的学生姓名：")  
            if change_name not in info:  
                print("该学生姓名在系统中不存在，请前往添加该学生~")  
                continue  
            chinese_score = float(input("请输入该学生的语文成绩："))  
            math_score = float(input("请输入该学生的数学成绩："))  
            english_score = float(input("请输入该学生的英语成绩："))  
            info[name] = {"chinese":chinese_score, "math":math_score, "english":english_score}  
            print("学生信息已修改~")  
  
        case '3':
            del_name = input("请输入要删除的学生姓名：")  
            if del_name not in info:  
                print("该学生姓名在系统中不存在，请前往添加该学生~")  
                continue  
            del info[del_name]  
            print("已删除该学生的信息~")  
  
        case '4':
            search_name = input("请输入要查询的学生姓名：")  
            if search_name not in info:  
                print("该学生在系统中不存在哦，请确认姓名是否有误~")  
                continue  
            stu_scores = info[search_name]  
            print(f"{search_name}同学的成绩分别为：语文{stu_scores['chinese']}，数学{stu_scores['math']}，英语{stu_scores['english']}")  
  
        case '5': 
            print("开始查询所有的学生信息~")  
            for s in info:  
                stu_scores = info[s]  
                print(f"{s}：语文{stu_scores['chinese']}，数学{stu_scores['math']}，英语{stu_scores['english']}")  
            print("已输出所有学生信息~")  
  
        case '6':
            if not info:  
                print("系统中暂无学生信息，请先添加~")  
                continue  
            # 1.把语文数学英语的成绩分别解包成三个列表。-->获取最高、最低、平均分  
            chinese,math,english = [],[],[]  
            cavg,mavg,eavg = 0,0,0  
            for s in info:  
                stu_scores = info[s]  
                c,m,e = stu_scores.values()  
                chinese.append(c)  
                math.append(m)  
                english.append(e)  
            cavg = sum(chinese)/len(chinese)  
            mavg = sum(math)/len(math)  
            eavg = sum(english)/len(english)  
  
            # 2.用列表推导式 语文、数学、英语最高分和最低分的学员姓名  
            max_chinese_stu = [name for name,scores in info.items() if scores["chinese"] == max(chinese)]  
            min_chinese_stu = [name for name,scores in info.items() if scores["chinese"] == min(chinese)]  
  
            max_math_stu = [name for name,scores in info.items() if scores["math"] == max(math)]  
            min_math_stu = [name for name,scores in info.items() if scores["math"] == min(math)]  
  
            max_english_stu = [name for name,scores in info.items() if scores["english"] == max(english)]  
            min_english_stu = [name for name,scores in info.items() if scores["english"] == min(english)]  
  
            print(f"班级的语文最高分为{max_chinese_stu}同学，{max(chinese)}分，最低分为{min_chinese_stu}同学，{min(chinese)}分，平均分为：{cavg:.2f}分；")  
            print(f"数学最高分为{max_math_stu}同学：{max(math)}分，最低分为{min_math_stu}同学：{min(math)}分，平均分为：{mavg:.2f}分；")  
            print(f"英语最高分为{max_english_stu}同学：{max(english)}分，最低分为{min_english_stu}同学：{min(english)}分，平均分为：{eavg:.2f}分；")  
  
        case '7':  
            print("退出系统ing~")  
            break  
        case _:  
            print("不支持的操作，请尝试~")
```
