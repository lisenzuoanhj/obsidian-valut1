## 一.条件判断
只有满足指定条件，才会执行对应的代码逻辑
if条件判断基本格式
```python
if 要判断的条件1:
	条件成立时，要执行的操作1
elif 要判断的条件2:  # elif可以写多个
	条件成立时，要执行的操作2
else:
	条件不成立时，要执行的操作3


year = int(input("请输入年份："))
if(year %100 != 0 and year %4 ==0) or (year %400 ==0):
	print(f"{year}是闰年")
else:
	print(f"{year}是平年")


a=int(input('请输入一个数字'))
if a>0:
     print('这是一个正数') 
elif a<0:
     print('这是一个负数')
else:
	 print("这是0")
```


> [!NOTE] 说明
> python中是通过缩进来描述代码归属的，归属于if代码块的语句，需要在前方缩进4个空格（Tab键）


## 二.结构模式匹配
结构模式匹配就是用一个清晰的模板去精准的匹配数据的结构和内容，匹配成功则执行相应的操作。
（图片）
**match...case语法**
```python
match 表达式:
    case 值1:
        操作1
    case 值2 if 条件表达式:
        操作2
    case 值3|值4:
        操作3
    case _:
        默认操作
```
应用场景：
- match：基于变量的多个固定值进行分支判断时，可以使用match模式匹配
- if：条件判断涉及复杂的逻辑判定、范围比较及组合条件时
## 三.循环
### 1.while循环
while循环的语法结构
```python
while 条件表达式:
    循环题语句1
    循环体语句2
    ...
else:  # 可不写
    条件为false，循环正常结束时执行

i= 0
while i<10:
    print("人生苦短")
    i +=1
else:
    print("循环结束，执行完毕")
```

> [!NOTE] 说明
> while循环通过条件表达式，来控制是否要进行下一次循环。


### 2.for循环
本质是一种**轮询遍历**机制，对一批内容进行逐个处理。

for循环结构
```python
for 元素 in 待处理数据集:
    循环体代码（对元素进行处理）
else:# 可不写
    循环结束时，执行的代码
 
 msg = "hello world"
 for i in msg:
     print(i)
else:
    print("循环结束")

```

for循环和while循环的应用场景
- while循环：用于在某个条件满足时一直循环，循环的次数通常是未知的，只知道循环开始和结束的条件。（关注循环条件）
- for循环：用于对一个已知的数据集进行遍历或已知次数的循环。（关注的是遍历每一个元素）

[[range]]

```python
# 用for循环计算1～100之间所有的奇数和
total = 0

for i in range(1,101)
    if i % 2 != 0
        total += i

print(f"1-100之间所有奇数的和为{total}")

# 可简化为
for i in range(1,101,2)
    total += i

# 计算100-500之间所有3的倍数的和
total = 0
for i in range(100,500)
    if(i % 3 == 0)
        total += i

print(f"100-200之间所有3的倍数的和为{total}")
```

### 3.嵌套循环
语法
```python
for 元素 in 待处理数据集1:
    循环体代码1
    循环体代码2
    ...
    for 元素 in 待处理数据集2:
        循环体代码1
        循环体代码2
        ...
    ...    

m = int(input("请输入长方形的宽"))
n = int(input("请输入长方形的长"))

for i in range(m):
	for j in range(n):
		print("*",end = " ")
	print()
```

**循环关键字：break，continue**
break：只能出现在循环中，表示结束，跳出循环的含义。跳出后，while
后面的else里面的代码将不会执行。
continue：只能出现在循环中，表示中断本次循环，直接进入下一次循环。

