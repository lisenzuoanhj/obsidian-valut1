## 一、定义

函数：一种组织好的、可重复使用的、用来实现特定功能的代码片段。
函数的定义和调用：
```python
# 定义函数
def 函数名（参数列表）:
    函数体
    ......
    return 返回值

def out_line():
    print('----------')

# 调用函数
函数名（参数）

out_pine()
```


> [!NOTE] 说明
> 函数定义时的参数列表和返回值语句是可有可无的（由需求确定）。
> 函数必须先定义后调用执行（函数定义时，内部代码并未执行，在调用时才执行）。
> 函数通过缩进来描述归属关系。


## 二、函数的参数与返回值
- 在定义函数时，根据业务需要，可以指定参数和返回值，具体格式如下：

```python
def 函数名（参数列表）：
    函数体
    ......
    return 返回值

# 计算圆的面积，周长
def circle_area_len(r):
    return 3.14 *r *r ,2 * 3.14 * r
    


# 调用函数
函数名（参数）

al = circle_area_len(10)
print(al) --> # 结果为“(314,62.80000000004)”  精度缺失
```


> [!NOTE] 说明
> 函数定义时如果有多个参数，多个参数之间用“,”分隔。
> return语句只有返回功能，没有输出打印功能，如果要输出，需要结合print()函数来实现。

- 参数列表里面是形参，只能在函数内部使用（局部变量）。
- 实际调用函数时传入的参数是实参。
- 多个返回值会封装到元组之中。


## 三、函数说明文档
函数说明文档是写在函数开头，用三个引号包裹的字符串，用于解释函数的功能、参数、返回值等信息，方便调用者了解函数的具体作用及细节。
```python
# 计算圆的面积，周长
def circle_area_len(r):
    """
    该函数用于根据圆的半径计算圆的面积和周长
    :param r:圆的半径
    :return:圆的面积，周长
    """
    return 3.14 *r *r ,2 * 3.14 * r

al = circle_area_len(10)
print(al)
```

- :param r：-->描述函数的参数
- :return:      -->描述函数的返回值

查看函数说明文档：
- 使用help函数，比如：help(circle_area_len)
- 鼠标悬浮在函数上，自动展示

## 四、函数嵌套调用

函数调用遵循栈结构，最后被调用的函数最先返回LIFO（后进先出）
```python
#函数的嵌套调用
def function_a():
    print("a... before")            function_b()
    print("a... after")

def function_b():
    print("b... before")            function_c()
    print("b... after")

def function_c():
    print("c...")

funqtion_a()

print("函数调用完毕。")
```

案例
```python
def tran_area(l,r):
    area = l*r/2
    return area
    
def count(str):
    num = 0
    for i in str:
        if i in 'aeiouAEIOU':
            num +=1
    return num
    
def score(nums):
    max_score = max(nums)
    min_score = min(nums)
    avg = sum(nums) / len(nums)    
    return max_score,min_score,avg
    
length = int(input("请输入三角形的底："))
hight =int(input("请输入三角形的高："))
area = tran_area(length,hight)
print(f"三角形的面积为{area}。")

str = input("请输入一个字符串：")
num = count(str)
print(f"该字符串里面有{num}个元音字母。")

sc =input("请输入成绩列表：")
nums = [float(x) for x in sc.split()]
h,l,a = score(nums)
print(f"列表中的最高分为{h:.1f}，最低分为{l:.1f}，平均分为{a:.1f}")
```
