今天研究了一些详细的代码。
`Optional<User> user = userRepository.findByUsernameAndPassword(username, password);`
1. Optional是在Java 8 引入的特性，它可以用来避免空指针异常。这行代码不返回直接的User对象，因为这样有可能会因为这个值不存在返回null，调用方忘了判断就报错。用Optional就可以避免报错，返回Optional< User >(一个“包裹”)。

2. 为什么用`findByUsernameAndPassword()`不需要写sql？
	 首先，这段代码是Java Persistence API（Java持久化技术中的一种流行的框架，简称JPA）中的一种方法。

3. JPA 会根据**方法名**自动生成 SQL。`findByUsernameAndPassword` 会被翻译成：
```sql
SELECT * FROM user WHERE username = ? AND password = ?
```
  
  4. 命名规则拆解：

| 方法名部分      | 含义               |
| ---------- | ---------------- |
| `findBy`   | 我要查询             |
| `Username` | 根据 `username` 字段 |
| `And`      | 并且               |
| `Password` | 根据 `password` 字段 |

所以 `findByUsernameAndPassword` = “根据 username 和 password 查”。
