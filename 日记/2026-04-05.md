`trim()` 是 Java 中字符串的一个方法，它的作用是**去掉字符串前后的空格**。

---

```java
String s1 = "  hello  ";
String s2 = s1.trim();  // s2 = "hello"

String s3 = "  用户名  ";
String s4 = s3.trim();  // s4 = "用户名"

String s5 = "没有空格";
String s6 = s5.trim();  // s6 = "没有空格"（不变）
```

---

## 为什么注册时要加 `trim()`？

```java
if (username == null || username.trim().isEmpty()) {
    return "用户名不能为空";
}
```
这行代码做了两件事：

1. **`username.trim()`**：去掉用户名前后的空格
2. **`.isEmpty()`**：判断去掉空格后是不是空字符串

**为什么要这样做？**

考虑这些情况：
- 用户输入：`"   "`（只敲了几个空格）
- 用户输入：`"  "`（只敲了空格）
- 用户输入：`""`（直接回车）

如果不加 `trim()`，`"   "` 不是空字符串（它有空格字符），校验就会通过，然后你把这个只有空格的内容存到数据库，显然不合理。
**加了 `trim()` 之后**：`"   ".trim()` 变成 `""`，然后 `isEmpty()` 返回 `true`，就会提示“用户名不能为空”。

---

## 常见的 `trim()` 使用场景

| 场景 | 没有 trim 的问题 | 有 trim |
|------|-----------------|---------|
| 登录时用户名 | 用户不小心敲了空格，比如 `"admin "` | 自动去掉空格，正常登录 |
| 注册时用户名 | 用户输入 `" 张三 "`，存进去带空格 | 存 `"张三"` |
| 表单输入框 | 用户只敲空格就提交 | 提示“不能为空” |

---
## 注意：`trim()` 只去掉首尾空格

```java
String s = "  hello  world  ";
s.trim();  // 结果："hello  world"
```

中间的空格（`hello` 和 `world` 之间的那两个空格）**不会被去掉**。

---
## 总结

| 方法 | 作用 |
|------|------|
| `trim()` | 去掉字符串**前后**的空格 |
| `isEmpty()` | 判断字符串长度是否为 0 |
| `isBlank()` (Java 11+) | 判断字符串是否是空白（空格、制表符等） |

也可以用 `isBlank()`：
```java
if (username == null || username.isBlank()) {
    return "用户名不能为空";
}
```

`isBlank()` 比 `trim().isEmpty()` 更简洁，效果一样。
