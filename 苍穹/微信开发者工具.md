一个小程序主体由三个文件构成，必须放在项目的根目录下：

| 文件       | 必需  | 作用       |
| -------- | --- | -------- |
| app.js   | 是   | 小程序逻辑    |
| app.json | 是   | 小程序公共配置  |
| app.wxss | 否   | 小程序公共样式表 |

一个小程序页面由四个文件组成：

| 文件类型 | 必需  | 作用    |
| ---- | --- | ----- |
| js   | 是   | 页面逻辑  |
| wxml | 是   | 页面结构  |
| json | 否   | 页面配置  |
| wxss | 否   | 页面样式表 |
