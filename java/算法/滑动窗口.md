
## 1. 什么是滑动窗口？（生活中的比喻）

想象你在**公交车上看窗外的风景**：
- 车窗就是你的"窗口"
- 车子向前开，窗口看到的风景在变化
- 但你始终只能看到窗外的一部分景色

**滑动窗口就是这样**：在数组或字符串上移动一个"窗口"，只关注窗口内的内容。

## 2. 最基本的滑动窗口例子

### 例子1：计算3个连续数字的最大和

假设数组：`[2, 1, 5, 1, 3, 2]`，我们要找**连续3个数字的最大和**

**传统方法（暴力解法）：**
```java
int[] arr = {2, 1, 5, 1, 3, 2};
int maxSum = 0;

// 方法1：用两个循环，计算每个可能的3个数字的组合
for (int i = 0; i <= arr.length - 3; i++) {
    int sum = 0;
    for (int j = i; j < i + 3; j++) {
        sum += arr[j];  // 重复计算了很多次
    }
    maxSum = Math.max(maxSum, sum);
}
System.out.println("最大和: " + maxSum); // 输出: 9
```

**问题**：这种方法有很多重复计算！

**滑动窗口方法：**
```java
int[] arr = {2, 1, 5, 1, 3, 2};
int k = 3; // 窗口大小

// 步骤1：先计算第一个窗口的和
int windowSum = 0;
for (int i = 0; i < k; i++) {
    windowSum += arr[i];
}
int maxSum = windowSum;

// 步骤2：滑动窗口
for (int i = k; i < arr.length; i++) {
    // 关键：不是重新计算整个窗口，而是减去离开的数字，加上新进入的数字
    windowSum = windowSum - arr[i - k] + arr[i];
    maxSum = Math.max(maxSum, windowSum);
}

System.out.println("最大和: " + maxSum); // 输出: 9
```

### 让我们一步步看看滑动窗口的过程：

初始数组：`[2, 1, 5, 1, 3, 2]`

**步骤1**：第一个窗口 `[2, 1, 5]`，和 = 8
```
窗口: [2, 1, 5] 和=8
数组:  2   1   5   1   3   2
       ↑       ↑
      left   right
```

**步骤2**：窗口向右滑动
- 去掉左边的2，加上右边的1
- 新窗口 `[1, 5, 1]`，和 = 8 - 2 + 1 = 7
```
窗口:   [1, 5, 1] 和=7
数组:  2   1   5   1   3   2
          ↑       ↑
         left   right
```

**步骤3**：继续滑动
- 去掉左边的1，加上右边的3  
- 新窗口 `[5, 1, 3]`，和 = 7 - 1 + 3 = 9
```
窗口:     [5, 1, 3] 和=9
数组:  2   1   5   1   3   2
              ↑        ↑
             left     right
```

**步骤4**：继续滑动
- 去掉左边的5，加上右边的2
- 新窗口 `[1, 3, 2]`，和 = 9 - 5 + 2 = 6
```
窗口:       [1, 3, 2] 和=6
数组:  2   1   5   1   3   2
                   ↑       ↑
                  left   right
```

**最终结果**：最大和是9

## 3. 可变大小的滑动窗口

### 例子2：找出和≥8的最短连续子数组

数组：`[2, 1, 5, 1, 3, 2]`，目标和 = 8

```java
public class SlidingWindowBasic {
    public static void main(String[] args) {
        int[] arr = {2, 1, 5, 1, 3, 2};
        int target = 8;
        
        int left = 0;       // 窗口左边界
        int currentSum = 0; // 当前窗口的和
        int minLength = Integer.MAX_VALUE; // 最短长度
        
        // right是窗口的右边界
        for (int right = 0; right < arr.length; right++) {
            // 步骤1：把右边的新数字加入窗口
            currentSum += arr[right];
            
            // 步骤2：当窗口的和≥目标时，尝试缩小窗口
            while (currentSum >= target) {
                // 更新最短长度
                int currentLength = right - left + 1;
                minLength = Math.min(minLength, currentLength);
                
                // 从窗口中移除左边的数字（缩小窗口）
                currentSum -= arr[left];
                left++; // 左边界向右移动
            }
        }
        
        // 如果找到了符合条件的子数组
        if (minLength != Integer.MAX_VALUE) {
            System.out.println("最短长度: " + minLength);
        } else {
            System.out.println("没有找到符合条件的子数组");
        }
    }
}
```

### 让我们一步步分析这个过程：

数组：`[2, 1, 5, 1, 3, 2]`，目标 = 8

**步骤1**：right=0，窗口`[2]`，和=2 < 8
```
窗口: [2] 和=2 < 8
数组:  2   1   5   1   3   2
      ↑
    left,right
```

**步骤2**：right=1，窗口`[2,1]`，和=3 < 8
```
窗口: [2, 1] 和=3 < 8  
数组:  2   1   5   1   3   2
      ↑   ↑
    left right
```

**步骤3**：right=2，窗口`[2,1,5]`，和=8 ≥ 8
- 找到符合条件的窗口，长度=3
- 尝试缩小：去掉左边的2，窗口`[1,5]`，和=6 < 8
```
窗口: [2, 1, 5] 和=8 ≥ 8 → 长度=3
然后:   [1, 5] 和=6 < 8
数组:  2   1   5   1   3   2
      ↑       ↑ →   ↑   ↑
     left   right  left right
```

**步骤4**：right=3，窗口`[1,5,1]`，和=7 < 8
```
窗口:   [1, 5, 1] 和=7 < 8
数组:  2   1   5   1   3   2
          ↑       ↑
         left   right
```

**步骤5**：right=4，窗口`[1,5,1,3]`，和=10 ≥ 8
- 找到符合条件的窗口，长度=4
- 尝试缩小：去掉左边的1，窗口`[5,1,3]`，和=9 ≥ 8，长度=3（更短！）
- 再缩小：去掉左边的5，窗口`[1,3]`，和=4 < 8
```
窗口:   [1, 5, 1, 3] 和=10 ≥ 8 → 长度=4
然后:     [5, 1, 3] 和=9 ≥ 8 → 长度=3（更优！）
然后:       [1, 3] 和=4 < 8
数组:  2   1   5   1   3   2
          ↑           ↑ → ↑ ↑
         left       right l r
```

**步骤6**：right=5，窗口`[1,3,2]`，和=6 < 8
```
窗口:       [1, 3, 2] 和=6 < 8
数组:  2   1   5   1   3   2
             ↑           ↑
            left       right
```

**最终结果**：最短长度是3（子数组`[5,1,3]`）

## 4. 滑动窗口模板

```java
public void fixedWindow(int[] arr, int k) {
    // 1. 计算第一个窗口
    int windowSum = 0;
    for (int i = 0; i < k; i++) {
        windowSum += arr[i];
    }
    
    // 2. 滑动窗口
    for (int i = k; i < arr.length; i++) {

    }
}

// 可变大小窗口模板  
public void variableWindow(int[] arr, int target) {
    int left = 0;
    int currentSum = 0;
    
    for (int right = 0; right < arr.length; right++) {
        // 1. 扩大窗口（右指针移动）
        currentSum += arr[right];
        
        // 2. 当满足条件时，缩小窗口（左指针移动）
        while (当前窗口满足某种条件) {
            // 更新结果
            currentSum -= arr[left];
            left++;
        }
    }
}
```

## 5. 什么时候使用滑动窗口？

当你遇到这些问题时，考虑滑动窗口：
- 找**连续子数组**的最大/最小和
- 找**连续子字符串**的最长无重复字符
- 找满足条件的**最短连续子数组**
- 问题要求**连续的**元素

刷题遇到的一些点：
1.遇到比大小类的题目时，要注意循环里面比大小的位置，要在窗口移动之前比较。
