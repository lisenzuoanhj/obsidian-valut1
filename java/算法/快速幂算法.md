```java
class Solution {
    public double myPow(double x, int n) {
        long N = n;
        return N >= 0 ? quickMul(x, N) : 1.0 / quickMul(x, -N);
    }

    public double quickMul(double x, long N) {
        if (N == 0) {
            return 1.0;
        }
        double y = quickMul(x, N / 2);
        return N % 2 == 0 ? y * y : y * y * x;
    }
}
```

## 1. 为什么需要快速幂？

先考虑一个简单的问题：如何计算 \( a^n \)（a 的 n 次幂）？

最直接的方法是连乘：
an=a×a×a×⋯×a(n 次)

这种方法的时间复杂度是 \(O(n)\)。

当 n 很大时（比如 \(n = 10^9\)），这种方法是不可行的，计算时间太长。

**快速幂**（Exponentiation by Squaring）可以在 \(O(\log n)\) 的时间内计算出 \(a^n\)，效率极高。

---

## 2. 快速幂的核心思想

快速幂的核心是**分治**与**二进制思想**。

### 2.1 分治思路

对于 \(a^n\)：

- 如果 n 是偶数：
  a^n = (a^{n/2})^2
  
- 如果 n 是奇数：an=a×an−1=a×(a(n−1)/2)2

这样不断递归下去，每次 n 的规模减半，所以递归深度是 \(O(\log n)\)。

### 2.2 二进制思路（更常用）

将指数 n 用二进制表示：

\[
n = (b_k b_{k-1} \dots b_1 b_0)_2
\]
那么：
\[
a^n = a^{b_k 2^k + b_{k-1} 2^{k-1} + \dots + b_1 \cdot 2 + b_0}
\]
\[
`a^n = a^{b_k 2^k} \times a^{b_{k-1} 2^{k-1}} \times \dots \times a^{b_1 \cdot 2} \times a^{b_0}`
\]

因为 \(a^{2^i} = (a^{2^{i-1}})^2\)，我们可以从低位到高位（或从高位到低位）迭代计算。

---

## 3. 迭代快速幂算法（二进制）

我们一边遍历 n 的二进制位，一边累乘。

**算法步骤**：
1. 初始化结果 `res = 1`
2. 令底数 `base = a`
3. 当指数 `n > 0`：
   - 如果 n 的二进制最低位为 1（即 `n % 2 == 1`），则 `res = res * base`
   - `base = base * base`（自乘，得到 a^{2^k}）
   - `n = n // 2`（右移一位，`n = n >> 1`）
4. 返回 `res`

**原理**：每次循环处理 n 的一个二进制位，如果该位是 1，就把当前的 base 乘到结果中。base 在每次循环时自乘，依次为 \(a^1, a^2, a^4, a^8, \dots\)。

---

## 4. 例子

### 例子1：计算 \(3^{13}\)

n = 13，二进制为 1101。

| n    | n 的二进制 | 最低位 | res（初始 1） | base（初始 3） |
|------|------------|--------|---------------|----------------|
| 13   | 1101       | 1      | 1×3 = 3       | 3×3 = 9        |
| 6    | 110        | 0      | 3             | 9×9 = 81       |
| 3    | 11         | 1      | 3×81 = 243    | 81×81 = 6561   |
| 1    | 1          | 1      | 243×6561 = 1594323 | 6561² |

结果：\(3^{13} = 1594323\)。

## 6. 时间复杂度分析

每次循环 n 减半，所以循环次数是 \(O(\log n)\)，每次循环做常数次乘法，因此总时间复杂度为 \(O(\log n)\)。


## 1. 基础快速幂实现

```java
public class FastExponentiation {
    
    /**
     * 快速幂算法（普通版本）
     * @param a 底数
     * @param n 指数
     * @return a 的 n 次幂
     */
    public static long fastPower(long a, long n) {
        long result = 1;
        long base = a;
        
        while (n > 0) {
            // 如果当前二进制位为1，将对应的幂乘到结果中
            if ((n & 1) == 1) {
                result *= base;
            }
            // 底数平方
            base *= base;
            // 指数右移一位
            n >>= 1;
        }
        
        return result;
    }
    
    public static void main(String[] args) {
        // 测试例子：3^13
        long a = 3;
        long n = 13;
        long result = fastPower(a, n);
        System.out.println(a + "^" + n + " = " + result);
        // 输出: 3^13 = 1594323
        
        // 验证
        System.out.println("验证: " + Math.pow(3, 13));
    }
}
```

## 2. 带模数的快速幂（防止溢出）

```java
public class ModularExponentiation {
    
    /**
     * 快速幂取模算法
     * @param a 底数
     * @param n 指数
     * @param mod 模数
     * @return a^n mod m
     */
    public static long fastPowerMod(long a, long n, long mod) {
        long result = 1;
        long base = a % mod;  // 先取模防止初始值过大
        
        while (n > 0) {
            if ((n & 1) == 1) {
                result = (result * base) % mod;
            }
            base = (base * base) % mod;
            n >>= 1;
        }
        
        return result;
    }
    
    public static void main(String[] args) {
        // 测试大数取模
        long a = 2;
        long n = 100;
        long mod = 1000000007;
        long result = fastPowerMod(a, n, mod);
        System.out.println(a + "^" + n + " mod " + mod + " = " + result);
        // 输出: 2^100 mod 1000000007 = 976371285
    }
}
```

## 3. 递归版本的快速幂

```java
public class RecursiveExponentiation {
    
    /**
     * 递归实现快速幂
     */
    public static long fastPowerRecursive(long a, long n) {
        if (n == 0) return 1;
        if (n == 1) return a;
        
        long half = fastPowerRecursive(a, n / 2);
        
        if (n % 2 == 0) {
            return half * half;
        } else {
            return half * half * a;
        }
    }
    
    /**
     * 递归实现快速幂取模
     */
    public static long fastPowerModRecursive(long a, long n, long mod) {
        if (n == 0) return 1 % mod;
        if (n == 1) return a % mod;
        
        long half = fastPowerModRecursive(a, n / 2, mod);
        half = (half * half) % mod;
        
        if (n % 2 == 1) {
            half = (half * a) % mod;
        }
        
        return half;
    }
    
    public static void main(String[] args) {
        System.out.println("递归快速幂 3^13 = " + fastPowerRecursive(3, 13));
        System.out.println("递归模幂 2^100 mod 1000000007 = " + 
            fastPowerModRecursive(2, 100, 1000000007));
    }
}
```

## 4. 处理负指数的情况

```java
public class AdvancedExponentiation {
    
    /**
     * 支持负指数的快速幂
     */
    public static double fastPowerAdvanced(double a, long n) {
        if (n < 0) {
            a = 1.0 / a;
            n = -n;
        }
        
        double result = 1.0;
        double base = a;
        
        while (n > 0) {
            if ((n & 1) == 1) {
                result *= base;
            }
            base *= base;
            n >>= 1;
        }
        
        return result;
    }
    
    public static void main(String[] args) {
        // 测试负指数
        System.out.println("2^(-3) = " + fastPowerAdvanced(2, -3));
        // 输出: 2^(-3) = 0.125
        
        // 测试小数底数
        System.out.println("0.5^4 = " + fastPowerAdvanced(0.5, 4));
        // 输出: 0.5^4 = 0.0625
    }
}
```

## 6. 实用工具类

```java
public final class MathUtils {
    
    private MathUtils() {} // 工具类，防止实例化
    
    /**
     * 快速幂计算
     */
    public static long pow(long base, long exponent) {
        if (exponent < 0) {
            throw new IllegalArgumentException("指数不能为负数: " + exponent);
        }
        
        long result = 1;
        while (exponent > 0) {
            if ((exponent & 1) == 1) {
                result *= base;
            }
            base *= base;
            exponent >>= 1;
        }
        return result;
    }
    
    /**
     * 快速幂模运算
     */
    public static long powMod(long base, long exponent, long mod) {
        if (mod <= 0) {
            throw new IllegalArgumentException("模数必须为正数: " + mod);
        }
        if (exponent < 0) {
            // 支持负指数：a^(-n) mod m = (a^(-1) mod m)^n mod m
            base = modularInverse(base, mod);
            exponent = -exponent;
        }
        
        long result = 1;
        base %= mod;
        
        while (exponent > 0) {
            if ((exponent & 1) == 1) {
                result = (result * base) % mod;
            }
            base = (base * base) % mod;
            exponent >>= 1;
        }
        
        return result;
    }
    
    /**
     * 模逆元（需要模数为质数）
     */
    private static long modularInverse(long a, long mod) {
        return powMod(a, mod - 2, mod); // 费马小定理
    }
    
    public static void main(String[] args) {
        // 测试工具类
        System.out.println("pow(3, 13) = " + MathUtils.pow(3, 13));
        System.out.println("powMod(2, 100, 1000000007) = " + 
            MathUtils.powMod(2, 100, 1000000007));
    }
}
```

## 关键要点说明

1. **位运算技巧**：
   - `n & 1` 代替 `n % 2` 检查奇偶性
   - `n >>= 1` 代替 `n /= 2` 进行除2操作

2. **防止溢出**：
   - 在模运算版本中，每一步都要取模
   - 使用 `long` 类型处理大数

3. **时间复杂度**：
   - 普通方法：O(n)
   - 快速幂：O(log n)

4. **适用场景**：
   - 大数幂运算
   - 密码学中的模幂运算
   - 动态规划优化
   - 矩阵快速幂
