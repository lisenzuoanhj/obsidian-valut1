[58.最后一个单词的长度](https://leetcode.cn/problems/length-of-last-word/)
这个也是一个简单题，但是我在处理的时候忘记的空格的位置的问题。
求最后一个单词的长度，倒序遍历当然是最方便的，但**末尾也可能有空格，还有可能有多个空格**。(while的由来)
```java
class Solution {
    public int lengthOfLastWord(String s) {
     int cnt=0;
     int len=s.length()-1;
     while(s.charAt(len)==' ')len-=1;
     for(int i=len;i>=0;i--){
        if(s.charAt(i)==' '){
            break;
        }
         cnt++;
     }  
     return cnt;
    }
 
}
```
