[最小偶倍数](https://leetcode.cn/problems/smallest-even-multiple/)
我知道这是一个很简单的题，但是这些解法我真的没想到。太厉害了。
```java
class Solution {
    public int smallestEvenMultiple(int n) {
        return (n % 2 + 1) * n;//这一段就是根据奇数答案为2n，偶数答案为n得来的
    }
}
```
还有一个是位运算，这个还是要学学
```java
class Solution {
    public int smallestEvenMultiple(int n) {
        return n << (n & 1);
    }
}
```
位运算利用的其实是二进制。1的二进制是0001，任何数与1进行按位与运算的结果只能是0或1，偶数为0，奇数为1。n<<k是左移位运算，表示把n的二进制左移k位，相当于×2的k次方。
