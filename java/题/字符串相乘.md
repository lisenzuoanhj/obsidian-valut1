[字符串相乘]
因为上一题是字符串相加，感觉相乘不过是变体，想着应该不难，但是还是难住了。
这个解法是模拟手算乘法的过程，把乘法拆解成多个加法。
```java
class Solution {
    public String multiply(String num1, String num2) {
        if (num1.equals("0") || num2.equals("0")) {
            return "0";
        }
        String ans = "0";
        int m = num1.length(), n = num2.length();
        for (int i = n - 1; i >= 0; i--) {
            StringBuffer curr = new StringBuffer();
            int add = 0;
            for (int j = n - 1; j > i; j--) {
                curr.append(0);
            }
            int y = num2.charAt(i) - '0';
            for (int j = m - 1; j >= 0; j--) {
                int x = num1.charAt(j) - '0';
                int product = x * y + add;
                curr.append(product % 10);
                add = product / 10;
            }
            if (add != 0) {
                curr.append(add % 10);
            }
            ans = addStrings(ans, curr.reverse().toString());
        }
        return ans;
    }

    public String addStrings(String num1, String num2) {
        int i = num1.length() - 1, j = num2.length() - 1, add = 0;
        StringBuffer ans = new StringBuffer();
        while (i >= 0 || j >= 0 || add != 0) {
            int x = i >= 0 ? num1.charAt(i) - '0' : 0;
            int y = j >= 0 ? num2.charAt(j) - '0' : 0;
            int result = x + y + add;
            ans.append(result % 10);
            add = result / 10;
            i--;
            j--;
        }
        ans.reverse();
        return ans.toString();
    }
}
```

### 1. 边界情况处理
```java
if (num1.equals("0") || num2.equals("0")) {
    return "0";
}
```
**解释**：任何数与0相乘结果都是0，这是最优化的边界情况处理。

**例子**：
- `"123" × "0" = "0"`
- `"0" × "456" = "0"`

### 2. 初始化变量
```java
String ans = "0";  // 累计结果，初始为0
int m = num1.length(), n = num2.length();  // 两个数字的长度
```

### 3. 外层循环 - 处理num2的每一位
```java
for (int i = n - 1; i >= 0; i--) {
```
**解释**：从num2的最低位（个位）开始，向高位处理。

### 4. 创建当前位的乘法结果
```java
StringBuffer curr = new StringBuffer();  // 存储当前位的乘法结果
int add = 0;  // 进位值
```

### 5. 补零操作 - 核心位权处理
```java
for (int j = n - 1; j > i; j--) {
    curr.append(0);
}
```
**详细解释**：
- 当处理num2的第i位时，该位实际上代表的是 `y × 10^(n-1-i)`
- 补零的数量 = `(n-1-i)`，这相当于乘以10的幂次

**例子**：`num2 = "45"` (n=2)
- i=1（个位5）：补0个零 → 5 × 10⁰
- i=0（十位4）：补1个零 → 4 × 10¹

### 6. 内层循环 - num2当前位与num1的每一位相乘
```java
int y = num2.charAt(i) - '0';  // 获取num2当前位的数字值
for (int j = m - 1; j >= 0; j--) {
    int x = num1.charAt(j) - '0';      // 获取num1当前位的数字值
    int product = x * y + add;         // 计算乘积加上进位
    curr.append(product % 10);         // 取个位作为当前位结果
    add = product / 10;               // 计算新的进位
}
```

**字符转数字原理**：
```java
'0' → 48, '1' → 49, ..., '9' → 57
'5' - '0' = 53 - 48 = 5
```

### 7. 处理剩余进位
```java
if (add != 0) {
    curr.append(add % 10);
}
```
**解释**：如果乘法结束后还有进位，需要添加到结果中。

### 8. 反转并累加到总结果
```java
ans = addStrings(ans, curr.reverse().toString());
```
**解释**：由于我们是从低位向高位构建的，需要反转得到正确顺序，然后与之前的结果相加。

## 大数加法方法详解

### addStrings方法
```java
public String addStrings(String num1, String num2) {
    int i = num1.length() - 1, j = num2.length() - 1, add = 0;
    StringBuffer ans = new StringBuffer();
    
    // 只要还有数字要处理或者有进位就继续
    while (i >= 0 || j >= 0 || add != 0) {
        int x = i >= 0 ? num1.charAt(i) - '0' : 0;  // 获取num1当前位，已结束则为0
        int y = j >= 0 ? num2.charAt(j) - '0' : 0;  // 获取num2当前位，已结束则为0
        int result = x + y + add;                   // 当前位相加加上进位
        ans.append(result % 10);                    // 取个位作为结果
        add = result / 10;                         // 计算新的进位
        i--; j--;                                  // 移动到下一位
    }
    
    ans.reverse();  // 反转得到正确顺序
    return ans.toString();
}
```

## 完整示例演示：`"123" × "45"`

### 初始状态
```
num1 = "123", num2 = "45"
ans = "0"
m = 3, n = 2
```

### 第一轮：处理num2的个位 '5' (i=1)

**步骤1：创建当前结果和进位**
```java
curr = StringBuffer(), add = 0
```

**步骤2：补零操作**
```java
for (int j = 1; j > 1; j--)  // 不执行，补0个零
```

**步骤3：逐位相乘**
- j=2: `x=3, y=5` → `product=3×5+0=15` → `curr="5"`, `add=1`
- j=1: `x=2, y=5` → `product=2×5+1=11` → `curr="51"`, `add=1`  
- j=0: `x=1, y=5` → `product=1×5+1=6` → `curr="516"`, `add=0`

**步骤4：处理剩余进位**
```
add=0，不需要处理
```

**步骤5：反转并累加**
```java
curr.reverse() = "615"
ans = addStrings("0", "615") = "615"
```

### 第二轮：处理num2的十位 '4' (i=0)

**步骤1：创建当前结果和进位**
```java
curr = StringBuffer(), add = 0
```

**步骤2：补零操作**
```java
for (int j = 1; j > 0; j--)  // 执行1次，补1个零
curr = "0"
```

**步骤3：逐位相乘**
- j=2: `x=3, y=4` → `product=3×4+0=12` → `curr="02"`, `add=1`
- j=1: `x=2, y=4` → `product=2×4+1=9` → `curr="029"`, `add=0`
- j=0: `x=1, y=4` → `product=1×4+0=4` → `curr="0294"`, `add=0`

**步骤4：处理剩余进位**
```
add=0，不需要处理
```

**步骤5：反转并累加**
```java
curr.reverse() = "4920"
ans = addStrings("615", "4920") = "5535"
```

### 最终结果
```
"123" × "45" = "5535" ✓
```

## 另一个例子：`"99" × "99"`

### 第一轮：处理个位 '9'
```
补0个零
9×99: 9×9=81 → 个位1进位8, 9×9+8=89 → 十位9进位8 → 百位8
中间结果: "891"
总和: "0" + "891" = "891"
```

### 第二轮：处理十位 '9'
```
补1个零
9×99: 9×9=81 → 个位1进位8, 9×9+8=89 → 十位9进位8 → 百位8
中间结果: "891" + "0" = "8910"
总和: "891" + "8910" = "9801"
```

最终结果：`"9801"` ✓

## 算法特点总结

1. **模拟手工计算**：完全按照人类手工计算乘法的步骤
2. **处理大数**：不受整数范围限制，可以处理任意长度的数字
3. **分解思想**：将复杂的大数乘法分解为多个简单的大数加法
4. **进位处理**：在乘法和加法中都妥善处理进位问题
5. **位权处理**：通过补零操作正确处理不同数位的权重

这个算法虽然时间复杂度较高，但是思路清晰，易于理解，是处理大数乘法的经典方法。
