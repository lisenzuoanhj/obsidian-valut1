[重新排列数组](https://leetcode.cn/problems/shuffle-the-array/)
因为有印象这个题之前没写出来，所以记录一下。
```java
class Solution {
    public int[] shuffle(int[] nums, int n) {
       int []numss=new int[2*n];
       for(int i=0;i<n;i++){
            numss[2*i]=nums[i];
            numss[2*i+1]=nums[i+n];
       }
       return numss;
    }
}
```
