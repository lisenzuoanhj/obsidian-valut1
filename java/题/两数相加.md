[两数相加](https://leetcode.cn/problems/add-two-numbers/)
```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode head = null, tail = null;
        int carry = 0;
        while (l1 != null || l2 != null) {
            int n1 = l1 != null ? l1.val : 0;
            int n2 = l2 != null ? l2.val : 0;
            int sum = n1 + n2 + carry;
            if (head == null) {
                head = tail = new ListNode(sum % 10);
            } else {
                tail.next = new ListNode(sum % 10);
                tail = tail.next;
            }
            carry = sum / 10;
            if (l1 != null) {
                l1 = l1.next;
            }
            if (l2 != null) {
                l2 = l2.next;
            }
        }
        if (carry > 0) {
            tail.next = new ListNode(carry);
        }
        return head;
    }
}
```
对于我唯一的问题：

- `head` 始终指向链表的**第一个节点**（头节点）
- `tail` 指向链表的**最后一个节点**（尾节点）
- 我们通过操作 `tail.next` 来**扩展链表**

## 执行过程分析：

假设我们要计算 342 + 465 = 807
- l1: 2 → 4 → 3
- l2: 5 → 6 → 4

**第一次循环：**
```java
sum = 2 + 5 + 0 = 7
head = tail = new ListNode(7)  // head指向节点7
```
链表：7

**第二次循环：**
```java
sum = 4 + 6 + 0 = 10
tail.next = new ListNode(0)  // 在节点7后面添加节点0
tail = tail.next             // tail现在指向节点0
```
链表：7 → 0

**第三次循环：**
```java
sum = 3 + 4 + 1 = 8
tail.next = new ListNode(8)  // 在节点0后面添加节点8
tail = tail.next             // tail现在指向节点8
```
链表：7 → 0 → 8

## 为什么返回 head 就可以了？

因为 `head` 始终指向链表的**起点**，而整个链表是通过节点之间的 `next` 指针连接起来的：

```
head
  ↓
  7 → 0 → 8 → null
              ↑
             tail
```

当我们返回 `head` 时，实际上返回的是整个链表，因为：
1. 从 `head` 可以访问第一个节点 (7)
2. 第一个节点的 `next` 指向第二个节点 (0)
3. 第二个节点的 `next` 指向第三个节点 (8)
4. 第三个节点的 `next` 为 null，表示链表结束

## 可视化理解：
```
初始: head = null, tail = null

循环1: head → 7 ← tail
循环2: head → 7 → 0 ← tail  
循环3: head → 7 → 0 → 8 ← tail
```

所以虽然代码一直在操作 `tail` 来添加新节点，但 `head` 始终指向链表的开头，返回 `head` 就能访问完整的链表。
