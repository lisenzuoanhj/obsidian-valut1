```java
class Solution {
    public int minCost(String colors, int[] neededTime) {
        int n=colors.length();
        int ans=0;
        for(int i=0;i<n-1;i++){
            if(colors.charAt(i)==colors.charAt(i+1)){
                ans+=neededTime[i]>neededTime[i+1]?neededTime[i+1]:neededTime[i];
            }
        }
        return ans;
    }
}
```
