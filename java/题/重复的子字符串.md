[459.重复的子字符串](https://leetcode.cn/problems/repeated-substring-pattern/)
给定一个字符串s，怎么判断s是否可以由其字串z重复组成？
e.g   s=' abaaba '那么它就是由字串' aba '重复两次组成的。
### 1.枚举
假设s的长度为n，z的长度为n‘，s由z组成，那么：
###### 1.z一定是s的前缀；n一定是n‘的倍数。
###### 2.对任意的i∈\[n',n)，s\[i]\==s\[i-n']。

e.g   a b a a b a
    0 1 2 3 4 5 
n=6，n'=3.
当i=4时，s\[i]='b';   s\[i-n‘]=s\[1]='b';
当i=5时，s\[i]='a';   s\[i-n‘]=s\[2]='a';

我们可以从小到大枚举出n'的大小，并遍历s。因为s由z重复得来，n'的长度必定不会超过n/2，所以我们只需在\[1,n/2]的范围内枚举n'.


```java
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        int n = s.length();
        for (int i = 1; i * 2 <= n; ++i) {
            if (n % i == 0) {
                boolean match = true;
                for (int j = i; j < n; ++j) {
                    if (s.charAt(j) != s.charAt(j - i)) {
                        match = false;
                        break;
                    }
                }
                if (match) {
                    return true;
                }
            }
        }
        return false;
    }
}

### 2.字符串匹配









```
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        return (s + s).indexOf(s, 1) != s.length();
    }
}
