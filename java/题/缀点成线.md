[缀点成线](https://leetcode.cn/problems/check-if-it-is-a-straight-line/)
```java
class Solution {
	 public boolean checkStraightLine(int[][] coordinates) {
		int dx=coordinates[0][0]; 
 	    int dy=coordinates[0][1]; 
		for(int i=0;i<coordinates.length;i++){
			coordinates[i][0]-=dx; 
			coordinates[i][1]-=dy; 
		} 
		int a=coordinates[1][0]; 
		int b=coordinates[1][1]; 
		for(int i=2;i<coordinates.length;i++){ 
			if(b*coordinates[i][0]-a*coordinates[i][1]!=0) 
				return false; 
			} 
		return true; 
	} 
}
```
照题解来的。两点连成一线，如果有一个是（0，0）就只需要一个点决定，所有这个代码里面最主要的操作是每个点都减去第一个点的x，y的大小，使第一个点在（0，0）处。用第二个点就能得到一个函数式。只要后面有一个点不符合就false。
