[丑数](https://leetcode.cn/problems/ugly-number/)
好吧其实这个题不难，只是我实在是没想明白。。
```java
class Solution {
    public boolean isUgly(int n) {
        if(n<=0)return false;
        int []factors={2,3,5};
        for(int factor:factors){
            while(n%factor==0)
            {
                n/=factor;
            }
        }
        return n==1;
    }
}
```
