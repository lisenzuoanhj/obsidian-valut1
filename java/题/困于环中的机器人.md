[1041. 困于环中的机器人](https://leetcode.cn/problems/robot-bounded-in-circle/)
这个题有几个重点。
1.只有G表示沿方向移动一个单位，L和R分别表示左转和右转90度。
2.如果移动指令instructions会导致机器人一直在环里移动，**返回true**。
写题的时候被这两个条件迷惑了，还以为用switch就可以了，第二个导致我最后的return出问题了。

```java
class Solution {
    public boolean isRobotBounded(String instructions) 
    {
       int x=0,y=0;
        int [][] dir={{0,1},{1,0},{0,-1},{-1,0}};
        int dirIndex=0;
        int len=instructions.length();
        for(int i=0;i<len;i++)
        {
            char re=instructions.charAt(i);
            if(re=='L')
            {
                dirIndex+=3;
                dirIndex%=4;
            }
            else if(re=='R')
            {
                dirIndex++;
                dirIndex%=4;
            }
            else if(re=='G')
            {
                x+=dir[dirIndex][0];
                y+=dir[dirIndex][1];
            }
        }
        return dirIndex!=0||(x==0&&y==0);
    }
}
```
这个代码我觉得最精妙的地方在于dir这个二维数组的设置。我一开始特别不理解对re\==‘G’条件的处理，问了ai才明白，其实是dir\[方向]\[坐标分量]。`x+=dir[dirIndex][0]`表示的是数组中第dirIndex个索引对应的两位数组中的0号索引对应的数。
### 示例：面向北 (`direcIndex = 0`)

```
java

direc[0] = {0, 1}  // x移动量=0, y移动量=+1

x += 0  // x坐标不变
y += 1  // y坐标+1（向上移动）
```

**效果**：从 (x,y) 移动到 (x, y+1)。
