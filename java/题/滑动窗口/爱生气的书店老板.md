[爱生气的书店老板](https://leetcode.cn/problems/grumpy-bookstore-owner/)
这个题最开始还是思路不对，想着是要用滑动窗口，但是我最开始想的只是单纯套到这个顾客的数组上，这样并不好区分生气不生气，看了一下灵神的题解，才知道可以分开计算，就是把不生气时的顾客数量单独算，然后再把生气时的单独做滑动窗口。后面还是犯错了，太心急了把滑出的的数字写成当前位置的，而不是应该滑出位置的了。
```java
class Solution {
    public int maxSatisfied(int[] customers, int[] grumpy, int minutes) {
        int cus=0;
        int madcus = 0;
        int mmadcus=0;
        int n=customers.length;
        for(int i=0;i<n;i++){
            if(grumpy[i]==0)cus+=customers[i];
            if(grumpy[i]==1)madcus+=customers[i];
            mmadcus = Math.max(mmadcus,madcus);
            if(i-minutes+1<0){continue;}
            int left = i-minutes+1;
            if(grumpy[left]==1)madcus-=customers[left];
        }
        return cus+mmadcus;
    }
}
```

然后是灵神的写法，我去。原来还可以用数组。
```java
class Solution {
    public int maxSatisfied(int[] customers, int[] grumpy, int minutes) {
        int[] s = new int[2];
        int maxS1 = 0;
        for (int i = 0; i < customers.length; i++) {
            s[grumpy[i]] += customers[i];
            int left = i - minutes + 1; // 窗口左端点
            if (left < 0) { // 窗口长度不足 minutes
                continue;
            }
            maxS1 = Math.max(maxS1, s[1]);
            // 窗口最左边元素离开窗口
            s[1] -= grumpy[left] > 0 ? customers[left] : 0;
        }
        return s[0] + maxS1;
    }
}
```
