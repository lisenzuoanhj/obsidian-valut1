[几乎唯一子数组的最大和](https://leetcode.cn/problems/maximum-sum-of-almost-unique-subarray/)
这个题其实我最开始是在纠结怎么记录数组里面出现的数字的次数。最开始想的是就多一个数组，出现哪个数字就对应的下标+1，但是看了看数据大小感觉太大了，后面检查数字的出现次数的时候要把整个数组遍历一遍会很耗时间，就放弃了。然后看题解发现可以用哈希表。~~我去 还是学少了~~
```java
class Solution {
    public long maxSum(List<Integer> nums, int m, int k) {
        Integer[] a = nums.toArray(Integer[]::new);
        long number =a.length;
        if(number<k)return 0;
        long ms =0;
        long s = 0;
        Map<Integer,Integer> son = new HashMap<>();
        for(int i=0;i<number;i++){
            s+=a[i];
            son.merge(a[i],1,Integer::sum);
            int left = i-k+1;
            if(left<0){continue;}
            if(son.size()>=m){ms=Math.max(s,ms);}
            int out =a[left];
            s-=out;
            Integer count =son.get(out);
            if(count>1)son.put(out,count-1);
            else {son.remove(out);}
        }
        return ms;
    }
}
```
注意大小，用long
