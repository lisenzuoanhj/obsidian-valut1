```java
//Definition for a binary tree node.
 public class TreeNode {
   int val;
   TreeNode left;
   TreeNode right;
   TreeNode() {}
   TreeNode(int val) { this.val = val; }
   TreeNode(int val, TreeNode left, TreeNode right) {
       this.val = val;
       this.left = left;
       this.right = right;
   }
}
```
这是一个**二叉树的节点类定义**的Java代码注释。
## 类结构
```java
public class TreeNode {
    // 类的成员变量和方法
}
```
定义了一个名为 `TreeNode` 的公共类，表示二叉树的一个节点。

## 成员变量
```java
int val;                    // 节点存储的值
TreeNode left;              // 左子节点的引用
TreeNode right;             // 右子节点的引用
```

## 构造函数

### 1. 无参构造函数
```java
TreeNode() {}
```
创建空节点，所有字段为默认值（val=0, left=null, right=null）

### 2. 带值构造函数
```java
TreeNode(int val) { 
    this.val = val; 
}
```
创建只有值，没有子节点的节点

### 3. 完整构造函数
```java
TreeNode(int val, TreeNode left, TreeNode right) {
    this.val = val;
    this.left = left;
    this.right = right;
}
```
创建包含值、左子节点和右子节点的完整节点

## 使用示例
```java
// 创建叶子节点
TreeNode leaf = new TreeNode(3);

// 创建有子节点的节点
TreeNode root = new TreeNode(1, 
    new TreeNode(2),        // 左子树
    new TreeNode(3)         // 右子树
);

// 创建更复杂的树
TreeNode complex = new TreeNode(1,
    new TreeNode(2, new TreeNode(4), new TreeNode(5)),
    new TreeNode(3, null, new TreeNode(6))
);
