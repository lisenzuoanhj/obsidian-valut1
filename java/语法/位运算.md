## 1. 基本位运算符

### `>>`（右移运算符）
```java
x >> n  // 将x的二进制表示向右移动n位
```
- **效果**：相当于除以 2ⁿ 并向下取整
- **例子**：
```java
  8 >> 1  // 8/2 = 4
  7 >> 1  // 7/2 = 3 (向下取整)
  6 >> 2  // 6/4 = 1
  ```

### `<<`（左移运算符）
```java
x << n  // 将x的二进制表示向左移动n位
```
- **效果**：相当于乘以 2ⁿ
- **例子**：
  ```java
  3 << 1  // 3*2 = 6
  4 << 2  // 4*4 = 16
  1 << 3  // 1*8 = 8
  ```

## 2. 相关的位运算符

### `>>>`（无符号右移）
```java
x >>> n  // 向右移动n位，左边空位补0
```
- 与 `>>` 的区别：对于负数，`>>` 补1，`>>>` 补0
- **例子**：
  ```java
  -8 >> 1   // = -4 (保持符号)
  -8 >>> 1  // = 2147483644 (无符号)
  ```

### `& 1`（检查奇偶性）
```java
x & 1  // 判断x是奇数还是偶数
```
- **效果**：`x & 1 == 1` 为奇数，`x & 1 == 0` 为偶数
- **例子**：
  ```java
  5 & 1  // = 1 (奇数)
  4 & 1  // = 0 (偶数)
  ```

## 3. 常见使用场景

### 场景1：快速乘除2的幂次
```java
// 乘法
x * 2   →   x << 1
x * 4   →   x << 2
x * 8   →   x << 3

// 除法
x / 2   →   x >> 1
x / 4   →   x >> 2
x / 8   →   x >> 3
```

### 场景2：取中间值（二分查找常用）
```java
int mid = (left + right) >> 1;  // 相当于 (left + right) / 2
```

### 场景3：判断奇偶性
```java
if ((x & 1) == 1) {
    // 奇数
} else {
    // 偶数
}
```

### 场景4：计算平均值（避免溢出）
```java
// 传统方法可能溢出
int avg = (a + b) / 2;

// 安全的方法
int avg = (a & b) + ((a ^ b) >> 1);
```

## 4. 实际应用示例

### 示例1：计算2的n次方
```java
int powerOfTwo(int n) {
    return 1 << n;  // 2ⁿ
}
```

### 示例2：判断是否是2的幂次
```java
boolean isPowerOfTwo(int x) {
    return x > 0 && (x & (x - 1)) == 0;
}
```

### 示例3：交换两个数（不使用临时变量）
```java
void swap(int a, int b) {
    a = a ^ b;
    b = a ^ b;
    a = a ^ b;
}
```

### 示例4：取绝对值
```java
int abs(int x) {
    int mask = x >> 31;          // 对于负数，mask = -1 (全1)
    return (x + mask) ^ mask;    // 巧妙的绝对值计算
}
```

## 5. 性能优势

位运算比对应的算术运算更快：
- `x >> 1` vs `x / 2`：右移更快
- `x << 1` vs `x * 2`：左移更快
- `x & 1` vs `x % 2`：位运算更快

## 6. 注意事项

1. **只适用于整数**：位运算只能用于整数类型
2. **注意负数**：右移负数时，`>>` 会保持符号位
3. **优先级**：位运算优先级较低，建议多用括号
4. **可读性**：在性能要求高的地方使用，普通代码优先考虑可读性

- **快速除以2**

- **各种数学优化的基础操作**
