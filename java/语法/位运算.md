
位运算直接对整数在内存中的二进制位进行操作，执行效率非常高。

## 基本的位运算符

### 1. 按位与（AND）`&`
**规则**：两个位都为1时，结果才为1
```java
int a = 5;    // 二进制: 0101
int b = 3;    // 二进制: 0011
int result = a & b;  // 0001 → 十进制 1
```

### 2. 按位或（OR）`|`
**规则**：两个位有一个为1时，结果就为1
```java
int a = 5;    // 0101
int b = 3;    // 0011
int result = a | b;  // 0111 → 十进制 7
```

### 3. 按位异或（XOR）`^`
**规则**：两个位不同时结果为1，相同时结果为0
```java
int a = 5;    // 0101
int b = 3;    // 0011
int result = a ^ b;  // 0110 → 十进制 6
```

### 4. 按位取反（NOT）`~`
**规则**：0变1，1变0
```java
int a = 5;    // 0000 0101
int result = ~a;     // 1111 1010 → 十进制 -6（补码表示）
```

### 5. 左移 `<<`
**规则**：将所有位向左移动，低位补0
```java
int a = 5;    // 0101
int result = a << 1; // 1010 → 十进制 10
// 相当于乘以2：5 * 2 = 10
```

### 6. 右移 `>>`
**规则**：将所有位向右移动，高位补符号位（算术右移）
```java
int a = 10;   // 1010
int result = a >> 1; // 0101 → 十进制 5
// 相当于除以2：10 / 2 = 5

int b = -8;   // 1111 1000 (补码)
int result2 = b >> 1; // 1111 1100 → 十进制 -4
```

### 7. 无符号右移 `>>>`
**规则**：将所有位向右移动，高位补0
```java
int a = -1;   // 1111 1111 1111 1111 1111 1111 1111 1111
int result = a >>> 1; // 0111 1111 1111 1111 1111 1111 1111 1111
```

## 常用位运算技巧

### 1. 判断奇偶性
```java
// 使用 n & 1
boolean isOdd = (n & 1) == 1;  // 为1是奇数，为0是偶数
```

### 2. 交换两个数（不使用临时变量）
```java
a = a ^ b;
b = a ^ b;  // b = (a ^ b) ^ b = a
a = a ^ b;  // a = (a ^ b) ^ a = b
```

### 3. 判断是否是2的幂
```java
boolean isPowerOfTwo = (n > 0) && ((n & (n - 1)) == 0);
```

### 4. 获取最低位的1
```java
int lowestOne = n & -n;
```

### 5. 消除最低位的1
```java
n = n & (n - 1);
```

### 6. 计算二进制中1的个数（汉明重量）
```java
// 方法1：消除最低位的1
int count = 0;
while (n != 0) {
    n &= (n - 1);
    count++;
}

// 方法2：使用内置函数
int count = Integer.bitCount(n);
```

## 实际应用场景

### 1. 权限管理系统
```java
// 定义权限
final int READ = 1;      // 0001
final int WRITE = 2;     // 0010  
final int EXECUTE = 4;   // 0100
final int DELETE = 8;    // 1000

// 授予权限
int userPermissions = READ | WRITE;  // 0011

// 检查权限
boolean canRead = (userPermissions & READ) != 0;
boolean canDelete = (userPermissions & DELETE) != 0;

// 添加权限
userPermissions |= EXECUTE;

// 移除权限
userPermissions &= ~WRITE;
```

### 2. 状态压缩
```java
// 表示集合 {0, 2, 3}
int set = (1 << 0) | (1 << 2) | (1 << 3);  // 0000 1101

// 检查元素是否存在
boolean hasElement2 = ((set >> 2) & 1) == 1;

// 添加元素
set |= (1 << 4);

// 删除元素  
set &= ~(1 << 2);
```

### 3. 颜色操作（ARGB）
```java
int alpha = (color >> 24) & 0xFF;
int red = (color >> 16) & 0xFF;
int green = (color >> 8) & 0xFF;
int blue = color & 0xFF;

// 重新组合颜色
int newColor = (alpha << 24) | (red << 16) | (green << 8) | blue;
```

## 注意事项

1. **运算符优先级**：位运算符优先级较低，建议多用括号
   ```java
   if ((a & b) == 0)  // 正确
   if (a & b == 0)    // 错误！== 优先级高于 &
   ```

2. **移位运算的位数**：对于int类型，实际移位次数是 `n % 32`

3. **负数处理**：注意有符号数和无符号数的区别。
