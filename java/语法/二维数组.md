## 1. 二维数组的基本概念

二维数组可以看作是一个表格，有行和列两个维度。

```java
// 声明一个二维数组
数据类型[][] 数组名;
```

## 2. 二维数组的声明和初始化

### 方式1：直接初始化
```java
// 声明并直接初始化
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};
```

### 方式2：先声明后初始化
```java
// 声明一个3行4列的二维数组
int[][] matrix = new int[3][4];

// 为数组元素赋值
matrix[0][0] = 1;
matrix[0][1] = 2;
// ...
```

### 方式3：不规则数组
```java
// 声明不规则二维数组（每行长度不同）
int[][] irregularArray = new int[3][];
irregularArray[0] = new int[2];  // 第一行2个元素
irregularArray[1] = new int[3];  // 第二行3个元素
irregularArray[2] = new int[1];  // 第三行1个元素
```

## 3. 访问二维数组元素

```java
int[][] scores = {
    {85, 90, 78},
    {92, 88, 95},
    {76, 85, 80}
};

// 访问第二行第三列的元素
int value = scores[1][2];  // 值为95

// 修改元素
scores[0][1] = 95;
```

## 4. 遍历二维数组

### 使用嵌套for循环
```java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 遍历所有元素
for (int i = 0; i < matrix.length; i++) {          // 遍历行
    for (int j = 0; j < matrix[i].length; j++) {   // 遍历列
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
```

### 使用增强for循环
```java
for (int[] row : matrix) {         // 遍历每一行
    for (int element : row) {      // 遍历当前行的每个元素
        System.out.print(element + " ");
    }
    System.out.println();
}
```

## 5. 二维数组的常用操作

### 获取数组维度
```java
int[][] arr = new int[3][4];

int rows = arr.length;        // 行数：3
int columns = arr[0].length;  // 列数：4（假设所有行长度相同）
```

### 矩阵转置示例
```java
public static int[][] transpose(int[][] matrix) {
    int rows = matrix.length;
    int cols = matrix[0].length;
    int[][] result = new int[cols][rows];
    
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            result[j][i] = matrix[i][j];
        }
    }
    return result;
}
```

## 6. 实际应用案例

### 案例1：学生成绩管理系统
```java
public class GradeManager {
    public static void main(String[] args) {
        // 3个学生，每个学生4门课程的成绩
        int[][] grades = {
            {85, 90, 78, 92},
            {88, 76, 95, 80},
            {92, 88, 79, 85}
        };
        
        // 计算每个学生的平均分
        for (int i = 0; i < grades.length; i++) {
            int sum = 0;
            for (int j = 0; j < grades[i].length; j++) {
                sum += grades[i][j];
            }
            double average = (double) sum / grades[i].length;
            System.out.printf("学生%d的平均分: %.2f\n", i + 1, average);
        }
    }
}
```

### 案例2：井字棋游戏
```java
public class TicTacToe {
    private char[][] board = new char[3][3];
    
    public TicTacToe() {
        // 初始化棋盘
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                board[i][j] = '-';
            }
        }
    }
    
    public void printBoard() {
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                System.out.print(board[i][j] + " ");
            }
            System.out.println();
        }
    }
    
    public boolean makeMove(int row, int col, char player) {
        if (board[row][col] == '-') {
            board[row][col] = player;
            return true;
        }
        return false;
    }
}
```

## 7. 注意事项

1. **数组索引从0开始**：第一行是`array[0]`，第一列是`array[0][0]`
2. **边界检查**：访问数组时要确保索引不越界
3. **内存分配**：二维数组在内存中不一定是连续存储的
4. **不规则数组**：Java支持每行长度不同的二维数组

## 8. 与一维数组的关系

实际上，Java中的二维数组就是一维数组的数组：

```java
int[][] arr = new int[3][4];
// 相当于：
// arr[0] = new int[4];
// arr[1] = new int[4];
// arr[2] = new int[4];
```

# Java 二维数组重要方法和相关操作

Java二维数组本身没有太多内置方法，但有很多重要的操作技巧和相关的工具类方法。

## 1. Arrays 类的常用方法

### 深度转换和比较
```java
import java.util.Arrays;

int[][] array1 = {{1, 2}, {3, 4}};
int[][] array2 = {{1, 2}, {3, 4}};

// 深度转换为字符串
String str = Arrays.deepToString(array1);
// 结果: "[[1, 2], [3, 4]]"

// 深度比较
boolean isEqual = Arrays.deepEquals(array1, array2);
// 结果: true

// 普通toString不适合二维数组
System.out.println(Arrays.toString(array1)); 
// 输出: [[I@1b6d3586, [I@4554617c] (不正确)
```

### 数组填充
```java
int[][] matrix = new int[3][3];

// 填充整个二维数组
Arrays.fill(matrix[0], 1);  // 第一行填充为1
Arrays.fill(matrix[1], 2);  // 第二行填充为2

// 或者遍历填充每一行
for (int[] row : matrix) {
    Arrays.fill(row, 0);  // 每行都填充为0
}
```

## 2. 重要的自定义操作方法

### 数组复制
```java
// 深拷贝二维数组
public static int[][] deepCopy(int[][] original) {
    if (original == null) return null;
    
    int[][] copy = new int[original.length][];
    for (int i = 0; i < original.length; i++) {
        copy[i] = Arrays.copyOf(original[i], original[i].length);
    }
    return copy;
}

// 使用
int[][] original = {{1, 2}, {3, 4}};
int[][] copy = deepCopy(original);
```

### 查找元素
```java
// 查找特定值的位置
public static int[] findElement(int[][] matrix, int target) {
    for (int i = 0; i < matrix.length; i++) {
        for (int j = 0; j < matrix[i].length; j++) {
            if (matrix[i][j] == target) {
                return new int[]{i, j};  // 返回行列索引
            }
        }
    }
    return new int[]{-1, -1};  // 未找到
}

// 使用二分查找在有序二维数组中查找
public static boolean searchMatrix(int[][] matrix, int target) {
    if (matrix == null || matrix.length == 0) return false;
    
    int row = 0;
    int col = matrix[0].length - 1;
    
    while (row < matrix.length && col >= 0) {
        if (matrix[row][col] == target) {
            return true;
        } else if (matrix[row][col] > target) {
            col--;
        } else {
            row++;
        }
    }
    return false;
}
```

## 3. 流式操作 (Java 8+)

```java
import java.util.Arrays;
import java.util.stream.*;

int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// 将二维数组转换为一维数组
int[] flatArray = Arrays.stream(matrix)
                       .flatMapToInt(Arrays::stream)
                       .toArray();
// 结果: [1, 2, 3, 4, 5, 6, 7, 8, 9]

// 计算所有元素的和
int sum = Arrays.stream(matrix)
               .flatMapToInt(Arrays::stream)
               .sum();

// 查找最大值
int max = Arrays.stream(matrix)
               .flatMapToInt(Arrays::stream)
               .max()
               .orElse(-1);

// 按行统计
int[] rowSums = Arrays.stream(matrix)
                     .mapToInt(row -> Arrays.stream(row).sum())
                     .toArray();
```

## 4. 矩阵运算方法

### 矩阵加减法
```java
// 矩阵加法
public static int[][] addMatrices(int[][] a, int[][] b) {
    if (a.length != b.length || a[0].length != b[0].length) {
        throw new IllegalArgumentException("矩阵维度不匹配");
    }
    
    int[][] result = new int[a.length][a[0].length];
    for (int i = 0; i < a.length; i++) {
        for (int j = 0; j < a[i].length; j++) {
            result[i][j] = a[i][j] + b[i][j];
        }
    }
    return result;
}
```

### 矩阵乘法
```java
// 矩阵乘法
public static int[][] multiplyMatrices(int[][] a, int[][] b) {
    int aRows = a.length;
    int aCols = a[0].length;
    int bRows = b.length;
    int bCols = b[0].length;
    
    if (aCols != bRows) {
        throw new IllegalArgumentException("矩阵维度不匹配，无法相乘");
    }
    
    int[][] result = new int[aRows][bCols];
    for (int i = 0; i < aRows; i++) {
        for (int j = 0; j < bCols; j++) {
            for (int k = 0; k < aCols; k++) {
                result[i][j] += a[i][k] * b[k][j];
            }
        }
    }
    return result;
}
```

## 5. 验证和工具方法

### 验证矩阵有效性
```java
// 检查是否为矩形矩阵（所有行长度相同）
public static boolean isRectangular(int[][] matrix) {
    if (matrix == null || matrix.length == 0) return false;
    
    int firstRowLength = matrix[0].length;
    for (int i = 1; i < matrix.length; i++) {
        if (matrix[i].length != firstRowLength) {
            return false;
        }
    }
    return true;
}

// 检查是否为方阵
public static boolean isSquare(int[][] matrix) {
    return isRectangular(matrix) && matrix.length == matrix[0].length;
}
```

### 矩阵转置
```java
// 矩阵转置
public static int[][] transpose(int[][] matrix) {
    if (!isRectangular(matrix)) {
        throw new IllegalArgumentException("不是矩形矩阵，无法转置");
    }
    
    int rows = matrix.length;
    int cols = matrix[0].length;
    int[][] result = new int[cols][rows];
    
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            result[j][i] = matrix[i][j];
        }
    }
    return result;
}
```
