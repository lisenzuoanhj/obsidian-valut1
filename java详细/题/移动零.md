[283. 移动零](https://leetcode.cn/problems/move-zeroes/)

把数组里所有的零移动到末尾（不是单纯输出移位！）。
**示例 1:**
**输入:** nums = `[0,1,0,3,12]`
**输出:** `[1,3,12,0,0]`
**示例 2:**
**输入:** nums = `[0]`
**输出:** `[0]`
###### 双指针法（~~其实一直以为是一个很高大上的方法~~）
```java
class Solution {
    public void moveZeroes(int[] nums) {
        int s=nums.length;
        int counter=0;
        for(int i=0;i<s;i++){
            if(nums[i]!=0){
                nums[counter]=nums[i];
                counter++;
            }
        }
        for(int i=counter;i<s;i++){
            nums[i]=0;
        }
    }
}
```
i和counter是两个指针。i按序遍历nums，counter用于记录0的个数，并在发现非零数的时候挪动其位置。

| 0   | 1   | 3   | 0   |
| --- | --- | --- | --- |
\  ^          ^
 \  |            |
counter     i
此时nums\[i]!=0，counter=0，则用nums\[counter]=nums\[i]将‘1’移到nums\[0]的位置，同时counter记录一次。
