[283. 移动零](https://leetcode.cn/problems/move-zeroes/)
把数组里所有的零移动到末尾（不是单纯输出移位！）。
###### 双指针法（~~其实一直以为是一个很高大上的方法~~）
```java
class Solution {
    public void moveZeroes(int[] nums) {
        int s=nums.length;
        int counter=0;
        for(int i=0;i<s;i++){
            if(nums[i]!=0){
                nums[counter]=nums[i];
                counter++;
            }
        }
        for(int i=counter;i<s;i++){
            nums[i]=0;
        }
    }
}
```
