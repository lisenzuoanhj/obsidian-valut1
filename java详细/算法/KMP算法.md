KMP算法是一个快速查找字符串的算法。在正式开始了解这个算法之前，我们要先了解前缀和后缀的概念。
对一个字符串`abcdccabc`,我们说它有这相同的前缀和后缀`abc`；前缀后缀都是可长可短的，也不是一定要相同。
*学习自`leetcode`的宫水三叶老师*。
![[Pasted image 20251007193429.png]]

正常匹配是从原串和匹配串的第一个依次开始遍历，可以看到在第六个字符出现了不符。
对KMP算法来说，它会先检查已经遍历过的字符串`abeab`里面是否存在相同的前后缀。容易知道有相同的前后缀`ab`。所以匹配串会从后缀之后开始重新匹配，又发现第三个字符不符。
