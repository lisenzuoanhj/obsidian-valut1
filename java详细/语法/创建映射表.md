在Java中，创建映射表（键值对集合）主要通过Map接口及其实现类来完成。以下是几种常见的创建方式：

## 1. Map接口概述

Map是存储键值对的数据结构，常用实现类有：
- `HashMap` - 最常用，无序存储
- `LinkedHashMap` - 保持插入顺序
- `TreeMap` - 按键排序

## 2. 基本创建方式

### 使用HashMap
```java
// 方式1：传统创建
Map<String, Integer> map1 = new HashMap<>();
map1.put("Alice", 25);
map1.put("Bob", 30);
map1.put("Charlie", 28);

// 方式2：使用静态初始化的双括号（匿名内部类）
Map<String, Integer> map2 = new HashMap<>() {{
    put("Alice", 25);
    put("Bob", 30);
    put("Charlie", 28);
}};
```

### 使用LinkedHashMap（保持插入顺序）
```java
Map<String, Integer> linkedMap = new LinkedHashMap<>();
linkedMap.put("Zoe", 22);
linkedMap.put("Alice", 25);
linkedMap.put("Bob", 30);

// 遍历时会按照插入顺序：Zoe → Alice → Bob
```

### 使用TreeMap（自动排序）
```java
Map<String, Integer> treeMap = new TreeMap<>();
treeMap.put("Zoe", 22);
treeMap.put("Alice", 25);
treeMap.put("Bob", 30);

// 遍历时会按键的字母顺序：Alice → Bob → Zoe
```

## 3. Java 9+ 的工厂方法

Java 9引入了更简洁的创建方式：

```java
// 创建不可变映射
Map<String, Integer> immutableMap = Map.of(
    "Alice", 25,
    "Bob", 30,
    "Charlie", 28
);

// 创建可变的映射（通过复制）
Map<String, Integer> mutableMap = new HashMap<>(Map.of(
    "Alice", 25,
    "Bob", 30
));
```

## 4. 使用Stream API创建

```java
import java.util.*;
import java.util.stream.*;

// 从数组创建
String[][] data = {{"A", "1"}, {"B", "2"}, {"C", "3"}};
Map<String, String> streamMap1 = Arrays.stream(data)
    .collect(Collectors.toMap(
        arr -> arr[0],  // 键
        arr -> arr[1]   // 值
    ));

// 从集合创建
List<String> keys = Arrays.asList("A", "B", "C");
List<Integer> values = Arrays.asList(1, 2, 3);
Map<String, Integer> streamMap2 = IntStream.range(0, keys.size())
    .boxed()
    .collect(Collectors.toMap(
        keys::get,
        values::get
    ));
```

## 5. 完整的示例代码

```java
import java.util.*;
import java.util.stream.*;

public class MapCreationExample {
    public static void main(String[] args) {
        // 1. 基本的HashMap
        Map<String, Integer> ageMap = new HashMap<>();
        ageMap.put("Alice", 25);
        ageMap.put("Bob", 30);
        ageMap.put("Charlie", 28);
        System.out.println("HashMap: " + ageMap);

        // 2. 使用Java 9的工厂方法
        Map<String, String> countryMap = Map.of(
            "CN", "China",
            "US", "United States",
            "JP", "Japan"
        );
        System.out.println("Immutable Map: " + countryMap);

        // 3. 使用Stream创建
        Map<Integer, String> numberMap = Stream.of(
            new AbstractMap.SimpleEntry<>(1, "One"),
            new AbstractMap.SimpleEntry<>(2, "Two"),
            new AbstractMap.SimpleEntry<>(3, "Three")
        ).collect(Collectors.toMap(Map.Entry::getKey, Map.Entry::getValue));
        System.out.println("Stream Map: " + numberMap);

        // 4. 特殊类型的Map
        // 有初始容量和负载因子的HashMap
        Map<String, Integer> customMap = new HashMap<>(16, 0.75f);
        
        // 线程安全的ConcurrentHashMap
        Map<String, Integer> concurrentMap = new ConcurrentHashMap<>();
    }
}
```

## 6. 重要注意事项

### 不可变映射
```java
// Java 9+ 的Map.of创建的是不可变映射
Map<String, Integer> immutable = Map.of("A", 1, "B", 2);
// immutable.put("C", 3); // 会抛出UnsupportedOperationException

// 创建可修改的副本
Map<String, Integer> mutable = new HashMap<>(Map.of("A", 1, "B", 2));
mutable.put("C", 3); // 正常执行
```

### 键的注意事项
- HashMap的键应该正确实现`equals()`和`hashCode()`方法
- TreeMap的键必须实现Comparable接口或提供Comparator

## 7. 选择指南

- **大多数情况**：使用 `HashMap`
- **需要保持插入顺序**：使用 `LinkedHashMap`
- **需要自动排序**：使用 `TreeMap`
- **线程安全需求**：使用 `ConcurrentHashMap`
- **小规模固定数据**：使用 `Map.of()` 工厂方法
